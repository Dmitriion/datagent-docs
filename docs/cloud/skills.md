# Навыки компании — готовые сценарии для агентов

**Навык** — готовая инструкция для агента: как проверить таблицу, как ответить клиенту, какой чеклист пройти перед отчётом. Вы **не пишете длинный промпт с нуля** — берёте сценарий из каталога и нажимаете **Установить**.

Если агенты каждый раз «забывают» правила компании — навык держит один и тот же сценарий для всей команды.

**Начните так:** [app.datagent.ru](https://app.datagent.ru) → **Навыки** → **Каталог** → найдите сценарий → **Установить** для компании.

**Навык** не заменяет [память](/docs/concepts/memory): навык говорит *что делать*, память хранит *факты компании*.

## Примеры навыков — что это даёт вам

| Навык (пример) | Что делает агент для оператора |
| --- | --- |
| **Работа с задачей** | Ведёт карточку по чеклисту: статус, комментарий, итог |
| **Проверка таблицы** | Находит ошибки в Excel до отправки отчёта руководству |
| **Ответ в CRM** | Готовит черновик по тону и правилам компании |
| **Документация и отчёт** | Собирает структуру документа из фактов в задаче |
| **Презентация** | Помогает оформить слайды по шаблону (нужен плагин Office) |
| **Разбор входящих** | Классифицирует обращение и предлагает следующий шаг |

Точные названия — в каталоге на [app.datagent.ru](https://app.datagent.ru); состав зависит от версии.

## Навык, плагин и память

| | **Навык** | **Плагин** | **Память** |
| --- | --- | --- | --- |
| Что это | Сценарий и тексты | Связь с Битрикс24, Excel… | Факты и правила компании |
| Кто включает | Менеджер в каталоге | Админ в [менеджере плагинов](./plugins) | Админ в разделе Память |

## Где открыть каталог

1. Боковое меню → **Навыки** → **Каталог**  
   или поиск (Ctrl+K) → «Каталог навыков».

| Вкладка | Содержимое |
| --- | --- |
| **От Datagent** | Стабильные сценарии с релизом |
| **Сообщество** | Таблицы, презентации, нишевые чеклисты |
| **Все** | Полный список |

**Установить** — навык ещё не в библиотеке компании. **Открыть** — уже установлен.

## Как пользоваться

1. Найдите навык в каталоге.
2. Нажмите **Установить**.
3. Если нужен плагин — панель предложит **включить** его (например Excel).
4. Подключите навык при создании агента или задачи.

:::tip Таблицы и слайды
Сценарии для Excel и презентаций — во вкладке **Сообщество**. Проверьте [плагины](./plugins) и [Excel на задаче](/docs/office/excel-pptx).
:::

## Частые вопросы

**Навык заменяет роль агента?**  
Нет — дополняет. Роль остаётся в настройках агента; навык даёт сценарий под тип задачи.

**Установил навык — Excel не работает.**  
Включите плагин для компании и разрешите агенту нужные действия.

**Где то же при первом агенте?**  
Краткий блок — [Первый агент](./first-agent#каталог-навыков).
