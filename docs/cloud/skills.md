# Навыки компании

**Навык** — это готовый набор инструкций для агента. Устанавливается из каталога за пару кликов и сразу расширяет возможности агента: чеклисты, шаблоны ответов, работа с таблицами и отчётами.

Если агенты каждый раз «забывают» правила компании — навык держит один и тот же сценарий для всей команды.

**Навык** не заменяет [память](/docs/concepts/memory): навык говорит *что делать*, память хранит *факты компании*.

**Первый шаг:** [app.datagent.ru](https://app.datagent.ru) → **Навыки** → **Каталог** → **Установить**.

## Навыки по тарифам

| Тариф | Навыков из каталога | Платные навыки |
| --- | --- | --- |
| **Free** | Бесплатные сценарии сообщества | — |
| **Solo** | 6 из 14 платных | — |
| **Studio** | Все 14 платных | ✅ включены |
| **Business** | Все 14 + **свои** навыки компании | ✅ приоритет |
| **Enterprise** | По договору | ✅ по договору |

Источник лимитов: [тарифы](./pricing). Подробная таблица при создании агента — [Первый агент → Каталог навыков](./first-agent#каталог-навыков).

## Как установить навык

1. Откройте раздел **Навыки** → **Каталог** в панели.
2. Найдите нужный навык (вкладки **От Datagent**, **Сообщество**, **Все**).
3. Нажмите **Установить** — при необходимости панель предложит включить **плагин** (например Excel).
4. Подключите навык при создании **агента** или **задачи**.

## Платные навыки

**Платные навыки** — расширенные сценарии для сложных задач: отчёты, презентации, конвертация документов, нишевые чеклисты. На **Solo** доступны **6 из 14**; полный набор — с **Studio**.

:::info Studio и выше
Все **14 платных навыков** каталога доступны начиная с тарифа **Studio**. На **Business** можно **импортировать свои** навыки компании.
:::

## Примеры — что это даёт вам

| Навык (пример) | Что делает агент |
| --- | --- |
| **Работа с задачей** | Ведёт карточку по чеклисту: статус, комментарий, итог |
| **Проверка таблицы** | Находит ошибки в Excel до отправки отчёта |
| **Ответ в CRM** | Готовит черновик по тону и правилам компании |
| **Документация и отчёт** | Собирает структуру документа из фактов в задаче |
| **Презентация** | Помогает оформить слайды (нужен плагин Office) |

Точные названия — в каталоге на [app.datagent.ru](https://app.datagent.ru).

## Навык, плагин и память

| | **Навык** | **Плагин** | **Память** |
| --- | --- | --- | --- |
| Что это | Сценарий и тексты | Связь с Битрикс24, Excel… | Факты и правила компании |
| Кто включает | Менеджер в каталоге | Админ в [менеджере плагинов](./plugins) | Админ в разделе Память |

## Частые вопросы

**Навык заменяет роль агента?**  
Нет — дополняет. Роль остаётся в настройках агента.

**Установил навык — Excel не работает.**  
Включите плагин для компании и разрешите агенту нужные действия — [Excel на задаче](/docs/office/excel-pptx).

**Где то же при первом агенте?**  
[Первый агент → Каталог навыков](./first-agent#каталог-навыков).
