# Навыки компании

:::info В разработке
Полная статья о навыках готовится — см. [план документации на Q3](/docs/meta/DOC-PLAN-2026-Q3).
:::

**Навык (skill)** — готовый сценарий для агента: пошаговые инструкции и чеклисты. Часть навыков просит включить **плагин** (Excel, Bitrix24). Каталог поставляется с Datagent и настраивается отдельно для каждой **компании**.

## Что будет на этой странице

- Открыть раздел **Навыки** в панели и включить нужное для компании
- Отличить **навык** от **плагина** и от **памяти** — три разных слоя возможностей
- Разобраться с community skills и встроенным каталогом
- Увидеть подсказки «включите плагин X» при активации навыка
- Понять тарифы и лимиты на свои навыки
