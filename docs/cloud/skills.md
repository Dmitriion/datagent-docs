# Навыки компании

> **Зачем:** Чтобы не писать длинную инструкцию агенту с нуля — взять готовый **навык** из каталога и за пару кликов включить для компании.

**Навык (skill)** — готовый сценарий: тексты, чеклисты, иногда требование включить **plugin**. Это не код и не замена [памяти](/docs/concepts/memory): навык говорит *что делать*, память хранит *факты компании*.

## Навык, плагин и память

| | **Навык** | **Плагин** | **Память** |
| --- | --- | --- | --- |
| Что это | Инструкция и сценарий | Код + worker + интеграция | Слои знаний компании |
| Кто включает | Менеджер в каталоге навыков | Админ в [менеджере плагинов](./plugins) | Админ в разделе Память |
| Пример | «Проверка таблицы перед отчётом» | Битрикс24, Excel Workbench | Тон общения, FAQ |

## Где открыть каталог

На [app.datagent.ru](https://app.datagent.ru):

1. Боковое меню → **Навыки** → **Каталог**  
   или поиск (Cmd+K / Ctrl+K) → «Каталог навыков»  
   или карточка агента → предложение установить навык.

| Вкладка | Содержимое |
| --- | --- |
| **От Datagent** | Встроенные навыки: работа с задачами, документация, проверки |
| **Сообщество** | Навыки сообщества: таблицы, презентации, аналитика |
| **Все** | Полный список |

Кнопка **Установить** — навык ещё не в библиотеке компании. **Открыть** — уже установлен. Нужно право создавать агентов.

## Это работает так

1. Найдите навык в каталоге (поиск по названию или тегу).
2. Нажмите **Установить** для своей компании.
3. Если навык требует плагин — панель предложит **включить** его (например Excel Workbench).
4. Пройдите короткий **чеклист настройки** после установки.
5. При создании агента или задачи подключите установленный навык — агент увидит инструкцию в контексте run.

:::tip Excel и презентации
Навыки для таблиц и слайдов — во вкладке **Сообщество**. После установки проверьте [менеджер plugin](./plugins) и [Excel на задаче](/docs/office/excel-pptx).
:::

## Community skills

Часть каталога — **community skills**: сценарии от сообщества, проходящие проверку качества в репозитории Datagent. Для облачного оператора разница простая: встроенные навыки стабильны с релизом; community — богаче по нишам, но могут требовать свежей версии instance.

Кастомные навыки своей компании (если доступны на тарифе) живут в той же библиотеке — отдельно от каталога «От Datagent».

## Тарифы

Базовый каталог доступен на **Free**. Лимиты на число активных навыков или кастомные пакеты зависят от тарифа и политики instance — смотрите [тарифы](./pricing) и настройки компании.

## Частые вопросы

**Навык заменяет system prompt?**  
Дополняет его. В prompt агента остаётся роль; навык даёт сценарий и чеклист под тип задачи.

**Установил навык — агент не видит Excel.**  
Проверьте, что плагин **включён** для компании и агенту разрешены tools плагина.

**Где то же самое при первом агенте?**  
Краткий блок — на странице [Первый агент](./first-agent#каталог-навыков-необязательно).

## Что дальше?

- **Установите плагины** — [plugins](/docs/cloud/plugins): без них часть навыков не заработает
- **Запустите первого агента** — [first-agent](/docs/cloud/first-agent): подключите навык при создании
- **Настройте память** — [memory](/docs/concepts/memory): факты компании отдельно от навыков
- **Соберите свой плагин** — [туториал](/docs/tutorials/build-plugin): если каталога мало
