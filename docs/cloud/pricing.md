## Free — познакомиться с одной AI-компанией

**Для кого:** solo founder или менеджер, который хочет **пилот** control plane без карты.

**Что входит:**

- **1 AI-компания**, до **3 агентов**
- **100 запусков (heartbeat)** в месяц
- Свои ключи API — BYOLLM
- [Согласования](../concepts/approvals) и журнал действий
- Agent Office — демо (без agent broker в чате)
- Бесплатные навыки в каталоге

**Когда переходить на Solo:** стабильно упираетесь в 100 запусков или нужны артефакты / Office Chat с агентами.

:::tip Типовой пилот
Один агент на **GigaChat**, 50–80 **запусков** в месяц — укладывается в Free.
[Начать →](https://app.datagent.ru/signup?plan=free)
:::

## Solo — один проект в бою

**Для кого:** indie developer / solo founder с **одной** AI-компанией.

**Цена:** **990 ₽/мес** ([начать с Solo →](https://app.datagent.ru/signup?plan=solo))

**Что добавляется к Free:**

- **1 AI-компания**, **без лимита агентов**, **1 000 запусков** в месяц
- Company Artifacts, export/import ZIP
- Office Chat с участием агентов
- Workspace File Viewer, учёт расходов по агентам
- Часть PRO-навыков (Solo allowlist — 6 из 14)
- Поддержка: email, SLA 48 ч

**Когда переходить на Studio:** нужна **вторая AI-компания**, команда из 2–3 человек, Bitrix24, sandbox BYOC или полный каталог PRO-навыков.

## Две оси: тариф и расход LLM

| | **Тариф (подписка)** | **Бюджет LLM (в компании)** |
| --- | --- | --- |
| Ограничивает | Число **AI-компаний**, **запусков** платформы, seats | Расход **токенов/₽** у провайдера |
| Кто платит | Datagent (Managed Cloud) | Вы провайдеру (BYOLLM) |

Лимит **запусков** ≠ **budget policies** в панели: бюджет — инструмент оператора; квота подписки — лимит платформы.

Подробнее про учёт расходов: [Как работают кредиты](../concepts/credits) (модель credit wallet — planned).

## Частые вопросы

**Можно ли навсегда остаться на Free?**  
Да, с лимитами 1 AI-компания / 3 агента / 100 запусков. Для ежедневной работы чаще нужен **Solo**.

**Тариф включает GigaChat?**  
Нет — ключи **ваши**. Тариф даёт **лимиты платформы** и возможности по плану.

**Есть ли скидка за год?**  
−20% при годовой оплате (см. таблицу выше) — после запуска биллинга.

**Что при смене тарифа?**  
Правила опубликуем при запуске оплаты; пока — [аккаунт](./account).
