## Кому подходит Cloud

- Владельцу и руководителю, которым нужен результат в панели, а не администрирование инфраструктуры.
- Команде, которая готова хранить рабочие данные Datagent на инфраструктуре сервиса в РФ.
- Тем, кто хочет проверить сценарии на **Free** или **Solo**, а интеграции к российским сервисам подключить на **Studio** и выше.

Если нужен полный контроль размещения и договор Enterprise — смотрите [свой контур](/docs/cloud/on-premise).

## Что вы получите после регистрации

1. Учётную запись и **мастер первых шагов** (создание компании).
2. Пространство компании: агенты, задачи, настройки.
3. Возможность создать агента (GigaChat, YandexGPT и др. — по вашим ключам) и поставить задачу.
4. Журнал шагов и контроль доступов.

Установка программ на свой сервер для обычной работы в Cloud **не нужна**. Отдельно может понадобиться расширение браузера только для сценариев [BrowserBridge](/docs/browser/setup).

## Тарифы — ориентир

| Тариф | Цена | Для кого |
| --- | --- | --- |
| **Free** | 0 ₽ | Попробовать: до 3 агентов, 100 запусков / мес |
| **Solo** | 990 ₽/мес | Один проект в ежедневной работе |
| **Studio** | 3 900 ₽/мес | Команда / агентство, коннекторы к российским сервисам |
| **Business** | 12 900 ₽/мес | Несколько проектов, роли, 1С |
| **Enterprise** | по договору | Свой контур и отдельные условия |

Вы платите за управление агентами в Cloud. Запросы к нейросетям — по **вашим** ключам. Подробности — [тарифы](/docs/cloud/pricing).
