# Datagent на своём сервере

> Эта страница для тех, кто устанавливает Datagent **на собственной инфраструктуре** (тариф **Enterprise**).  
> Если нужно просто начать работу — вам в облако: **[app.datagent.ru](https://app.datagent.ru/signup)**.

Для большинства команд удобнее **облако** на [app.datagent.ru](https://app.datagent.ru): регистрация и первый агент за несколько минут.

Если по политике безопасности данные и программа должны находиться **только у вас** — оформляется тариф **Enterprise**: установка в вашем контуре, договор, гарантия доступности и поддержка. Это не «скачал и поставил сам за вечер» — внедрение ведём вместе с вашей IT-службой.

## Чем облако отличается от своего сервера

| | Облако | Свой сервер (Enterprise) |
| --- | --- | --- |
| Где данные | У Datagent, в РФ | На вашем оборудовании |
| Как начать | [Регистрация](https://app.datagent.ru/signup) → [начало работы](./getting-started) | Заявка и проект внедрения |
| Тариф | **Free**, **Solo** (990 ₽), **Studio** (3 900 ₽), **Business** (12 900 ₽) | **Enterprise** — от ~100 000 ₽/мес, по договору |
| Интеграции | Битрикс24 с **Studio**, 1С с **Business** | Те же коннекторы в вашем контуре |
| Поддержка | По тарифу облака | Персональный менеджер, гарантия 99,9% |

**Business (12 900 ₽/мес)** — это **облако** для компании с ролями, 1С и высоким лимитом запусков. **Не** установка на вашем сервере.

В этой справке **нет** пошаговой инструкции «поставьте контейнер на боевой среде» для обычных пользователей — для промышленной эксплуатации на своём оборудовании работаем через отдел продаж и внедрения.

## Как оставить заявку

Напишите на **[sales@datagent.ru](mailto:sales@datagent.ru?subject=Заявка%20на%20Enterprise%20Datagent&body=Компания%3A%0AКонтакт%3A%0AОжидаемое%20число%20агентов%3A%0AТребования%20ИБ%3A)** и кратко укажите:

- название компании и контактное лицо;
- сколько агентов и запусков в месяц ожидаете;
- требования по безопасности (изоляция, регион, единый вход);
- желаемые сроки запуска.

Ответим с предложением по **Enterprise** и планом внедрения.

## Частые вопросы

**Можно ли поставить Datagent самим?**  
Для промышленной эксплуатации на своём сервере — **проект внедрения Enterprise**. Исходники открыты для изучения; обновления и поддержка — по договору.

**Чем отличается от app.datagent.ru?**  
Данные и инфраструктура у вас; те же интеграции (**GigaChat**, **Битрикс24**), изолированный контур.

**С чего начать?**  
Пилот в [облаке](./getting-started) или заявка на [sales@datagent.ru](mailto:sales@datagent.ru).
