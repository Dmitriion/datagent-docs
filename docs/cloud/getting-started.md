# Первый агент за 5 минут

⏱ Займёт: 5 минут · 🎯 Результат: агент выполнил первую задачу

> **Зачем:** Проверить AI-агента на реальной задаче — без серверов, Docker и программиста.

**Datagent** — облако на [app.datagent.ru](https://app.datagent.ru). Регистрация — 1 минута. Установка на свой сервер не нужна.

:::tip Доступно бесплатно
**Free** — 0 ₽, **3 агента**, **100 запусков** в месяц. GigaChat и YandexGPT без оплаты подписки Datagent.
[Зарегистрироваться →](https://app.datagent.ru/signup)
:::

## Шаг 1 — Создайте аккаунт (1 мин)

Откройте [app.datagent.ru/signup](https://app.datagent.ru/signup). Укажите почту и пароль. Нажмите «Зарегистрироваться».

**Что увидите:** экран входа в панель Datagent.

## Шаг 2 — Создайте компанию (30 сек)

Пройдите **мастер настройки**. Введите название компании. Подтвердите.

**Что увидите:** пустую панель с разделами «Агенты» и «Задачи». Дальнейшие разделы — [настройки компании](/docs/concepts/company-settings).

## Шаг 3 — Создайте агента (1 мин)

**Агенты → Новый агент.** Имя — например, «Помощник». Модель — **GigaChat** или **YandexGPT** ([инструкции](../integrations/gigachat)). Сохраните.

**Что увидите:** карточку агента в списке.

Подробнее по полям: [Первый агент](./first-agent).

## Шаг 4 — Дайте задачу (1 мин)

Создайте **задачу** для агента. Напишите одну фразу: «Перечисли 3 идеи, как автоматизировать ответы клиентам в CRM». Нажмите **Запустить**.

**Что увидите:** статус «выполняется» на карточке задачи.

## Шаг 5 — Посмотрите результат (30 сек)

Откройте **журнал запуска** в задаче. Прочитайте шаги агента и итоговый ответ.

**Что увидите:** текст ответа и список действий — не переписку «как в чате».

***

✅ **Готово.** Ваш первый агент работает.

## Что вам не понадобится

- Node.js, PostgreSQL или Docker на своём сервере
- Клонировать репозиторий с GitHub
- Нанимать разработчика «чтобы просто попробовать»

Свой сервер — только **Enterprise**: [Свой сервер](./on-premise).
