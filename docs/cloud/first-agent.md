# Как создать первого агента

Разберём поля агента, навыки по тарифу и типичные сбои — чтобы первый запуск был не пробным, а рабочим. Если вы ещё не в панели — сначала [начало работы](./getting-started) за пять минут.

## Быстрый путь

1. Пройдите [регистрацию и компанию](./getting-started) на [app.datagent.ru](https://app.datagent.ru).
2. Откройте **Агенты → Новый агент** — имя, **тип подключения к модели** (адаптер), модель, секреты.
3. Создайте задачу, нажмите **Запустить** — результат появится в журнале.

## Адреса в панели

У каждой компании свой **префикс** в адресе:

```text
https://app.datagent.ru/{префикс}/agents/new
https://app.datagent.ru/{префикс}/agents/{id-агента}
https://app.datagent.ru/{префикс}/issues/{номер-задачи}
```

Нет компании — откроется мастер первых шагов. Вход по ссылке-приглашению от коллеги; обычный вход — через страницу входа.

## Создание агента

![Форма нового агента — имя, модель, инструкция](/img/guides/agents/09-edit-form.webp)

1. Откройте [app.datagent.ru](https://app.datagent.ru) и выберите **компанию**.
2. Перейдите в **Агенты → Новый агент**.
3. Заполните поля (пример для помощника по продажам):

| Поле в панели | Пример значения |
| --- | --- |
| Имя | `lead-helper` |
| Тип адаптера | `gigachat_local` или `yandexgpt_local` |
| Модель | `gigachat/GigaChat-2-Pro` или `yandexgpt/rc` |
| Каталог (только Yandex) | ID каталога в Yandex Cloud (`b1g…`) |
| Секреты | Ключи GigaChat или JSON ключа сервисного аккаунта Yandex |

Имена адаптеров в таблице — технические идентификаторы в панели; в интерфейсе вы выбираете GigaChat или YandexGPT.

4. **Инструменты** — только из **включённых** плагинов. Управление браузером — с тарифа **Studio** и выше. Битрикс24 и Телеграм работают через задачи и чаты, не отдельной галочкой — см. [Битрикс24](../integrations/bitrix24.md), [Телеграм](../integrations/telegram.md).

5. **Системная инструкция** (пример):

```text
Ты ассистент. Отвечай кратко на русском.
Используй только те инструменты, которые указаны в настройках.
```

6. Нажмите **Сохранить**, затем **Проверить окружение** в настройках компании — так вы убедитесь, что ключи модели работают.

Подробнее о ключах: [GigaChat](../integrations/gigachat.md), [YandexGPT](../integrations/yandexgpt.md), [адаптеры](../concepts/llm-adapters.md).

## Запуск агента

На карточке агента или в задаче нажмите **Запустить**. Пример поручения:

```text
Составь чек-лист из трёх пунктов для звонка новому клиенту.
```

В журнале видны ответы модели и вызовы инструментов: в очереди, выполняется, успешно, ошибка. **Агент приступил к работе** — дальше смотрите журнал, пока статус не станет «успешно».

## Каталог навыков

Откройте **Навыки → Каталог** — из меню, поиска в панели или с карточки агента.

| Вкладка | Содержимое |
| --- | --- |
| **От Datagent** | Встроенные навыки: документация, проверки, работа с задачами |
| **Сообщество** | Навыки сообщества: таблицы, презентации, аналитика |
| **Все** | Полный список |

**Установить** — навык ещё не в библиотеке компании; **Открыть** — уже установлен. После установки пройдите короткий чеклист настройки.

### Какие навыки на каком тарифе

Платные навыки каталога — **14 штук**. Доступ зависит от тарифа (после включения оплаты в продукте):

| Тариф | Платные навыки каталога |
| --- | --- |
| **Free** | Только бесплатные навыки (таблицы, презентации базового уровня, анализ данных и др.) |
| **Solo** | **6 из 14:** анализ Excel, отчёты Excel, питч-дек, слайды по данным, экспорт в Markdown, конвертация DOC/PDF в Markdown |
| **Studio** и выше | **Все 14**, включая аналитику (Pandas, Polars), визуализацию, Power BI, статистику |
| **Business** | Все 14 + импорт **своих** навыков |

Если тариф **Solo**, а навык требует **Studio** — это один из восьми «студийных» (тяжёлая аналитика и BI), не из шести для Solo.

### Навыки для Excel и презентаций

Установите навык из вкладки **Сообщество**. Панель может **автоматически включить** плагин для таблиц и слайдов. Перед запуском проверьте список возможностей. Подробнее: [Excel и PowerPoint](../office/excel-pptx.md).

## Если агент не справился

1. **Уточните задачу** — одна конкретная цель вместо «сделай всё».
2. **Добавьте навык** из каталога, если нужен Excel, отчёт или презентация.
3. **Проверьте ключи модели** и лимит запусков по [тарифу](./pricing).

## Частые вопросы

**Сколько агентов на Free?**  
До **3 агентов** и **100 запусков** в месяц — [Тарифы](./pricing).

**Обязательно GigaChat?**  
Нет. Часто начинают с [GigaChat](../integrations/gigachat.md) или [YandexGPT](../integrations/yandexgpt.md).

**Почему нет «Битрикс24» в инструментах?**  
CRM подключается через задачи и чаты — [Битрикс24](../integrations/bitrix24.md).

<details>
<summary>Запуск из командной строки (для разработчиков)</summary>

```bash
export AGENT_ID="<uuid-агента>"
curl -s -X POST "https://app.datagent.ru/api/agents/${AGENT_ID}/wakeup" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "on_demand",
    "reason": "учебный пример",
    "payload": { "note": "Чек-лист для звонка" }
  }'
```

Журнал запуска — через API обзора в [документации API](../api-reference/overview.md).

</details>
