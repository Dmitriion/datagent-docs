## Когда тест можно открыть сотрудникам

Тест без вопросов не публикуется. Если есть открытые вопросы, нужен **пул проверяющих** — люди, которые смотрят ответы. Без пула публикация не пройдёт.

Тест может быть отдельным назначением или модулем курса. В каталоге и при старте попытки работает только опубликованный тест.

## Что фиксируется, когда сотрудник начал тест

При старте попытки EDPortal сохраняет снимок настроек: проходной балл, правила пересдачи, таймеры, видимость балла и список проверяющих. Оценка смотрит на этот снимок, а не на «живой» тест, который методист мог поменять позже.

| Результат | Когда |
| --- | --- |
| Сдан | Балл не ниже порога из снимка попытки |
| Не сдан | Балл ниже порога |
| На проверке | Есть открытые ответы, ждёт проверяющего |

Сертификат выдаётся по правилам опубликованного материала после успешного результата. Это не страница базы знаний.

## Открытые ответы и оценка 360

Проверяющий видит очередь ответов. Это не полный журнал компании: журнал смотрят администратор и HR. В интерфейсе роль проверяющего называется ассесор.

Оценка 360 живёт отдельно, в студии. Цикл запускает HR или модератор. Сотрудник не стартует её из плеера теста.

## Если тест стоит внутри курса

Тест в модуле курса не даёт закрыть модуль, пока попытка не завершена. После сдачи сотрудник возвращается в [плеер курса](/docs/apps/edportal/courses).
