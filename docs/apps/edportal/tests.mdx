## Публикация теста

Тест без вопросов не публикуется. Если есть открытые вопросы, нужен **пул проверяющих** — иначе публикация не пройдёт.

Тест может быть отдельным назначением или модулем курса. Каталог и старт попытки работают только с опубликованным тестом.

## Что происходит в попытке

При старте попытки EDPortal фиксирует настройки теста (порог, политика пересдачи, таймеры, видимость балла, пул проверяющих). Оценка смотрит на этот снимок, а не на «живой» тест, который методист мог поменять позже.

| Результат | Когда |
| --- | --- |
| Сдан | Балл не ниже порога из снимка попытки |
| Не сдан | Балл ниже порога |
| На проверке | Есть открытые ответы, ждёт ассесора |

Сертификат выдаётся по правилам опубликованного контента после успешного результата — не как страница «базы знаний».

## Открытые вопросы и оценка 360

Ассесор видит очередь проверки. Это не полный журнал компании: аудит — у администратора и HR.

Отдельно в студии есть циклы оценки 360: сценарий запускает HR или модератор, не сотрудник из плеера теста.

## Связь с курсами

Тест в модуле курса блокирует завершение модуля, пока попытка не закрыта. Сотрудник возвращается в [плеер курса](/docs/apps/edportal/courses) после сдачи.
