## Поддерживаемые мессенджеры

| Канал | Назначение |
| --- | --- |
| **Telegram** | Бот или личный аккаунт по сценарию мастера; deeplink для первого контакта, если мессенджер требует приглашение |
| **VK** | Сообщения сообщества; склейка диалога с Telegram и MAX по телефону при настройке маршрутизации |
| **MAX** | Канал в статусе бета; те же правила доставки в Открытую линию |

Все три — **официальные каналы для РФ**, не прокси стороннего inbox.

## Как подключить канал

1. Откройте **мастер** из карточки приложения или виджета контакт-центра.
2. Выберите мессенджер и пройдите OAuth или укажите токен бота — по подсказкам мастера.
3. Привяжите канал к **Открытой линии** портала (см. [линии](/docs/apps/connector/lines)).
4. Отправьте тестовое сообщение: диалог должен появиться в чате линии у оператора.

Статус канала виден в виджете **контакт-центра** на портале. Ошибки OAuth или истёкший токен отображаются там же — без отдельного кабинета Wazzup.

## Вложения и исходящие

- Входящие **тексты и вложения** передаются в объёме, который поддерживает API мессенджера и Открытых линий.
- Исходящие ответы оператора уходят обратно в тот же канал из чата линии.
- Запись в CRM (лид, контакт, сделка) — только с явным согласием в настройках; AI Datagent Core на доставку не влияет.

## Чего в каналах нет

- Нет отдельного inbox вне Открытых линий Битрикс24.
- Нет плагина ИИ-агентов Datagent Cloud — см. [Битрикс24](/docs/integrations/bitrix24).
- Нет произвольных webhook для сторонних CRM: транспорт заточен под `imconnector` / `imopenlines`.

Настройка линий и SLA — на странице [Открытые линии](/docs/apps/connector/lines).
