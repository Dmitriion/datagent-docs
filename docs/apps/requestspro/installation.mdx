## Какие документы принять

- [Лицензионное соглашение Заявки PRO](https://datagent.ru/legal/requestspro-license)
- [Политика конфиденциальности Заявки PRO](https://datagent.ru/legal/requestspro-privacy)

Не подставляйте вместо них договор Datagent Cloud и политику платформы агентов.

## Что делает мастер

Приложение создаёт хранилища `entity` с кодами `rpro_groups` и `rpro_rights`, кладёт справочники в кэш и подписывается на события `ONAPPUNINSTALL` и `ONAPPUPDATE`. Пункт меню (`BX24.installFinish()`) появляется только после успеха.

Повторная установка не затирает уже собранный каталог. Удаление без очистки сбрасывает токены на стороне приложения. Удаление с очисткой (`CLEAN`) дополнительно чистит кэш этого портала. Хранилище на портале при очистке убирает Битрикс24.

Второй портал — другой `member_id`. Каталоги не пересекаются.
