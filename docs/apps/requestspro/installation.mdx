## Что происходит при установке

Приложение создаёт схему `entity` (`rpro_groups`, `rpro_rights`), кэширует справочники и вешает `ONAPPUNINSTALL` / `ONAPPUPDATE`. `BX24.installFinish()` вызывается только после успеха.

Повторная установка идемпотентна: каталог на месте. Удаление без очистки сбрасывает токены на стороне приложения; с очисткой (`CLEAN`) дополнительно очищается кэш тенанта, хранилище на портале убирает Битрикс24.

Второй портал — другой `member_id`, каталоги не пересекаются.
