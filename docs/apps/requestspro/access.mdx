## Кто может менять каталог

Роль в приложении совпадает с **администратором портала Битрикс24**, а не с правом «настройки приложений». Изменить группы, порядок, права, кэш и иконки с чужой учётной записи нельзя: сервер проверяет пользователя через REST портала.

Сотрудник без прав администратора не создаёт группы и не открывает редактирование. При попытке приложение отвечает «недостаточно прав».

## Когда сотрудник видит карточку

Администратор видит все карточки. Для остальных:

| Правило | Результат |
| --- | --- |
| Стоит «всем» (public) | Карточка видна |
| Списки отделов и людей пусты | Карточка видна |
| Сотрудник указан лично | Карточка видна |
| Отдел сотрудника есть в списке отделов | Карточка видна |
| Иначе | Карточка скрыта |

Права задаются на карточку процесса, не на группу целиком. Группа, в которой сотруднику не видна ни одна карточка, ему не показывается.

ФИО в интерфейсе берутся из кратких карточек `user_brief`, без контактных данных полного права `user`.

## Где лежат права

Коды хранилищ на портале: `rpro_groups` и `rpro_rights`. Это данные **вашего портала**, не общий каталог Datagent Cloud.

Если удалить приложение с очисткой данных, каталог на портале удаляется вместе с ним. Кэш справочников привязан к `member_id` портала и очищается при удалении.

## Что проверить на живом сотруднике

1. Создайте группы под процессы портала — см. [каталог](/docs/apps/requestspro/catalog).
2. Для каждой карточки укажите «всем» или списки отделов и сотрудников.
3. Зайдите под учёткой без прав администратора: лишних карточек быть не должно.
