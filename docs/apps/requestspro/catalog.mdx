## Как собрать каталог

1. Администратор создаёт **группу**. Обычные разделы: Кадры, Закупки, IT.
2. В группу добавляет **бизнес-процессы** из справочника портала.
3. Задаёт порядок групп и при необходимости иконку карточки.
4. Сотрудник в меню видит только группы, где есть хотя бы одна доступная ему карточка.

Если каталог пуст, администратор видит предложение создать первую группу. Сотрудник без карточек видит сообщение, что заявок нет, без кнопок настройки.

## Откуда берутся процессы

Справочник читается из инфоблока типа **`bitrix_processes`**. Это процессы, которые уже настроены на портале. Заявки PRO их не проектирует и не подменяет своим маршрутом согласования.

Нажатие по карточке открывает процесс портала (`/bizproc/processes/…`). Право `bizproc` приложению не нужно: заявку ведёт Битрикс24.

## Откуда берутся сотрудники и отделы

При установке и по кнопке «Обновить справочники» подтягиваются отделы, сотрудники и процессы. Кэш отделов и сотрудников — около 30 минут, процессов — около 60 минут. Событие «добавили сотрудника» не используется.

Иконку можно загрузить в приложение. Картинку процесса с Диска портала как файл прочитать нельзя: право `disk` не запрашивается.

## Чего в каталоге нет

- Нет конструктора маршрутов согласования вместо бизнес-процессов портала.
- Нет публичного REST «создать заявку в Заявки PRO».
- Нет выгрузки каталога на чужие порталы: данные привязаны к `member_id` вашего портала.

Права на карточку — на странице [доступ](/docs/apps/requestspro/access).
