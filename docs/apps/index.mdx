## Как получить доступ

Устанавливает **администратор портала** из 1С-Битрикс24.Маркетплейс. Отдельной подписки у ООО «ДАТАДЖЕНТ» и оплаты через ЮKassa нет: условия оплаты — договор пользователя с Битриксом.

Лицензия и политика каждого приложения — на datagent.ru, не оферта Cloud и не политика платформы агентов:

- [EDPortal: лицензия](https://datagent.ru/legal/edportal-license) · [конфиденциальность](https://datagent.ru/legal/edportal-privacy)
- [Заявки PRO: лицензия](https://datagent.ru/legal/requestspro-license) · [конфиденциальность](https://datagent.ru/legal/requestspro-privacy)
- [Datagent Connector: лицензия](https://datagent.ru/legal/connector-license) · [конфиденциальность](https://datagent.ru/legal/connector-privacy)
