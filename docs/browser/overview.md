# Подключите браузер к агенту

:::info Studio и выше
**BrowserBridge** доступен начиная с тарифа **Studio** (3 900 ₽/мес). На **Free** и **Solo** управление браузером недоступно. [Тарифы →](/docs/cloud/pricing)
:::

**BrowserBridge** позволяет агенту работать в браузере как человек: открывать сайты, заполнять формы, нажимать кнопки, скачивать файлы. Команды приходят из [app.datagent.ru](https://app.datagent.ru), страницы открываются на **вашем** компьютере.

**Первый шаг:** [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **BrowserBridge** → мастер **«Облако + ПК»**.

## Когда это нужно

- Выгружать отчёты из систем **без API**
- Заполнять формы на сторонних сайтах
- Проверять витрину или статус заказа на сайте перевозчика
- Работать в разделе CRM, где нет отдельной связки с чатами

## Пример

Агент каждый день заходит в личный кабинет поставщика, скачивает прайс-лист и обновляет цены в таблице. Без API — вы подтверждаете отправку формы в [согласованиях](/docs/concepts/approvals).

## Как подключить

1. Включите плагин **BrowserBridge** в **Менеджере плагинов**.
2. На рабочем ПК пройдите мастер **«Облако + ПК»** — скрипты свяжут браузер с облаком.
3. Дождитесь статуса **«В сети»** — агент сможет выполнять действия на разрешённых сайтах.

Подробные шаги — [Подключение BrowserBridge](./setup). Справка по интеграции — [BrowserBridge](/docs/integrations/browserbridge).

## Что умеет агент в браузере

- **Открыть страницу** — статус заказа, когда у перевозчика нет готовой связки с CRM.
- **Снять текст или скриншот** — приложить доказательство к задаче.
- **Заполнить форму** — отправка только после вашего «Одобрить».
- **Работать в разделе Битрикс24** — там, где нет отдельной связки с чатами.

:::tip Подходит для
Заявки на сайтах, внутренние порталы, проверка витрины, разделы CRM только в браузере.
:::

:::warning Не подходит для
Банк-клиентов и сайтов с жёсткой защитой от роботов.
:::

## Частые вопросы

**Нужен ли свой сервер?**  
Нет — [app.datagent.ru](https://app.datagent.ru), ПК с Node.js 20+ и браузером.

**Это облачный браузер?**  
Нет. Страницы открываются в **вашем** Chrome или Edge.

**Какой тариф?**  
**Studio** (3 900 ₽/мес) или **Business**. На Free и Solo — недоступно.
