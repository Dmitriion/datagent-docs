# Подключите браузер к агенту

Агент заполняет формы на сайтах, снимает скриншоты и работает в CRM через **ваш** Chrome или Edge — команды идут из [app.datagent.ru](https://app.datagent.ru), страницы открываются на рабочем ПК.

> **Доступно на тарифе Studio и выше.**  
> На тарифах **Free** и **Solo** управление браузером недоступно. [Тарифы →](/docs/cloud/pricing)

## Как это работает (коротко)

1. Включите плагин **BrowserBridge** в панели (**Studio+**).
2. На рабочем ПК пройдите мастер «Облако + ПК» — скрипты свяжут браузер с облаком.
3. Агент выполняет действия на сайте; опасные шаги — через [подтверждения](/docs/concepts/approvals).

Подробные шаги — [Подключение BrowserBridge](./setup). Справка по интеграции — [BrowserBridge](/docs/integrations/browserbridge).

## Что умеет браузер-агент

- **Открыть страницу** — статус заказа без API перевозчика.
- **Снять текст или скриншот** — доказательство в задаче.
- **Заполнить форму** — отправка только после вашего «Одобрить».
- **Работать в CRM в браузере** — раздел Битрикс24, куда нет отдельного API.

:::tip Подходит для
Формы, сбор данных с сайтов, внутренние порталы без API, проверка витрины.
:::

:::warning Не подходит для
Банк-клиентов и сайтов с жёсткой антибот-защитой.
:::

## Частые вопросы

**Нужен ли свой сервер?**  
Нет — [app.datagent.ru](https://app.datagent.ru), ПК с Node.js 20+ и браузером.

**Это облачный браузер?**  
Нет. Страницы — в **вашем** браузере; облако отдаёт команды агенту.

**Какой тариф?**  
**Studio** (3 900 ₽/мес) или **Business**. На Free и Solo — недоступно.
