# Подключение BrowserBridge

Агент сможет работать с реальными сайтами на вашем компьютере: открывать страницы, снимать скриншоты, заполнять формы под вашим контролем.

Если вы уже на тарифе **Studio** или **Business**, путь простой:

1. Установите [Datagent BrowserBridge из Chrome Web Store](https://chromewebstore.google.com/detail/datagent-browserbridge/onlphfpiiegbgjmfihbimgnmpbleaelh?hl=ru).
2. В [app.datagent.ru](https://app.datagent.ru) выпустите токен в разделе **BrowserBridge**.
3. Вставьте токен в расширение и разрешите нужные сайты.

Сервер Datagent на ПК ставить не нужно.

## Что нужно

- Тариф **Studio** или **Business** ([тарифы →](/docs/cloud/pricing))
- Браузер **Google Chrome** (рекомендуется; также поддерживаются Chromium-браузеры по сценарию компании)
- Аккаунт на [app.datagent.ru](https://app.datagent.ru)

> На **Free** и **Solo** BrowserBridge недоступен.

## Шаг 1 — Установить расширение

1. Откройте [Datagent BrowserBridge в Chrome Web Store](https://chromewebstore.google.com/detail/datagent-browserbridge/onlphfpiiegbgjmfihbimgnmpbleaelh?hl=ru) и нажмите **Установить**.
2. Войдите в [app.datagent.ru](https://app.datagent.ru).
3. **Менеджер плагинов** → установите и **включите** **BrowserBridge** (если ещё не включён).
4. Откройте **Настройки компании → BrowserBridge**.

## Шаг 2 — Подключить токен

1. На странице BrowserBridge выпустите **персональный токен** сопряжения.
2. Откройте **popup** расширения (иконка Datagent в панели Chrome).
3. Вставьте токен и нажмите **Сохранить**.
4. Дождитесь статуса подключения к Board (**«В сети»** / подключено).

Токен привязан к вашему аккаунту: у коллег — свои токены.

## Шаг 3 — Разрешить сайты и политику

1. В popup расширения нажмите **«Разрешить все сайты»** или разрешите конкретный домен (нужно для скриншотов и работы на внешних сайтах).
2. В панели Datagent задайте **политику адресов** — какие сайты разрешены агенту (например, пресет CRM для `*.bitrix24.ru`).
3. В карточке агента включите работу с браузером.

## Шаг 4 — Проверить, что агент видит браузер

1. Откройте **боковую панель** (Side Panel) расширения — справа можно держать задачу Datagent, пока агент работает на сайте.
2. Создайте задачу с простым адресом из разрешённого списка (или через боковую панель с режимом работы в браузере) и запустите.
3. В журнале задачи появятся шаги: переход, клик, ввод, скриншот или извлечение текста.
4. В шапке панели индикатор BrowserBridge должен быть **«В сети»**.

### Что умеет агент после подключения

- Переход по адресу страницы
- Клики, ввод в поля, прокрутка
- Извлечение текста и таблицы
- Скриншоты страницы (после разрешения сайтов)
- Пауза автоматизации с панели на странице
- Задача Datagent в боковой панели рядом с целевым сайтом

## Типичные проблемы

| Симптом | Что сделать |
| --- | --- |
| «Офлайн» / не подключается | Выпустите новый токен, вставьте в расширение снова |
| «Переход заблокирован» | Добавьте домен в политику адресов в панели |
| Нет скриншота | В popup расширения разрешите сайт или «все сайты» |
| Агент не открывает сайт | Включите плагин и работу с браузером в карточке агента |
| Капча, СМС, банк | Такие сайты обычно не подходят — см. [обзор](./overview) |

## Частые вопросы

**Нужен ли Datagent на ПК?**  
Нет — только расширение Chrome и токен из облачной панели.

**Нужен ли Node.js?**  
Для обычного пути через Chrome Web Store — **нет**.

**Работает на Solo?**  
Нет — нужен **Studio** или выше.

**Где политика конфиденциальности?**  
[datagent.ru/privacy](https://datagent.ru/privacy/)
