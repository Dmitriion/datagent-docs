# Конвейеры

**Конвейер** — это многоэтапный процесс в панели: заявки, документы или проверки проходят по этапам, агенты выполняют шаги, а вы принимаете решения в одном месте.

Конвейеры доступны **всем пользователям по умолчанию**. В левой навигации компании откройте пункт **Конвейеры**.

## Какую задачу решает

Обычная **задача** — одно поручение одному агенту.  
**Конвейер** нужен, когда работа повторяется и проходит несколько стадий: приём → проверка человеком → доработка → готово.

Без конвейера такие процессы живут в чатах и таблицах. С конвейером видно, **где** элемент, **кто** ждёт решения и **что** уже одобрено.

## Практический пример

Отдел согласования договоров:

1. Менеджер массово добавляет новые договоры на первый этап.
2. Агент готовит краткую сводку и отмечает риски.
3. Руководитель в **очереди на проверку** одобряет, отклоняет или запрашивает правки.
4. После одобрения элемент переходит на этап «Готово» — без переписки «где файл?».

То же подходит для заявок в поддержку, контроля качества отчётов и пакетной обработки документов.

## Что вы получите

| Возможность | Зачем |
| --- | --- |
| Список и доска конвейеров | Обзор всех процессов компании |
| Этапы и карточки | Понятный статус каждого элемента |
| Очередь на проверку | Все решения человека в одном списке |
| Массовое добавление | Пачка заявок одним действием |
| Автоматизация этапа | Агент отрабатывает шаг по правилам этапа |
| «Спросить агента» | Диалог по элементу открывается в разделе «Офис» |

:::tip[Важно]
В карточке конвейера **нет** встроенного чата как в задаче. Кнопка **«Спросить агента»** открывает диалог в **Офисе**. История элемента конвейера и **Таймлайн** запусков — разные экраны.
:::

## Когда брать конвейер, а когда задачу

| Ситуация | Что открыть |
| --- | --- |
| Один разово вопрос агенту | [Задача](../concepts/issues) |
| Повторяющийся поток с этапами и проверкой | **Конвейер** |
| Нужно увидеть, кто из агентов работал по времени | [Таймлайн](./timeline) |
| Нужен полный журнал действий компании | Раздел **Активность** в панели компании |

## Как начать

1. Откройте [app.datagent.ru](https://app.datagent.ru) и выберите компанию.
2. В левой навигации нажмите **Конвейеры**.
3. Создайте конвейер кнопкой **+** (подсказка «Новый конвейер»).
4. Задайте название и описание, сохраните.
5. В **настройках** конвейера опишите этапы: инструкции, автоматизацию, кто проверяет.
6. На доске нажмите **Добавить элементы** — заполните одну или несколько строк и отправьте.
7. Разберите **Очередь на проверку**, когда элементы ждут решения.

## Автоматизация и агенты

На этапе можно задать автоматизацию: агент получает связанные задачи и двигает процесс по правилам конвейера. Жёлтые предупреждения на доске подсказывают, если этап настроен не до конца (нет агента, нет инструкций).

Согласования найма и стратегии агента — это [отдельный механизм одобрений](../concepts/approvals), не путайте с очередью конвейера.

## Ограничения

- Конвейер не заменяет учётную систему: для 1С и CRM используйте [интеграции](../integrations/1c-connector).
- Не обещайте «чат прямо в карточке конвейера» — диалог идёт через **Офис**.
- Перетаскивание пальцем на телефоне намеренно отключено, чтобы не мешать прокрутке.

## Ключевые факты

- Конвейеры доступны всем пользователям компании без отдельного флага.
- Очередь проверки конвейера и раздел «Согласования» агента — разные механизмы.
- «Спросить агента» открывает диалог в Офисе, не чат внутри карточки конвейера.

## Частые вопросы

**Нужно ли включать что-то у администратора?**  
Нет. Конвейеры — стандартный раздел панели для компании.

**Чем отличается от задач?**  
Задача — одно поручение. Конвейер — поток элементов по этапам с массовой работой и очередью проверки.

**Где смотреть историю запусков агентов по времени?**  
В [Таймлайне](./timeline), не в истории элемента конвейера.
