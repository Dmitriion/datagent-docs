# Как передать файл агенту

Вы можете **передать агенту файл** как часть задачи — на **любом тарифе**, включая **Free**. Агент прочитает вложение и использует в работе.

**Файл результата** (Excel, PDF и т.д.) и общий [каталог артефактов](./overview) — с тарифа **Solo+**. На **Free** ответ чаще остаётся **текстом** в задаче.

## Какие файлы принимает агент

- **Документы:** PDF, Word (`.docx`), текстовые файлы
- **Таблицы:** Excel (`.xlsx`), CSV
- **Изображения:** JPG, PNG и другие распространённые форматы
- **Презентации:** PowerPoint (`.pptx`)
- **Архивы:** ZIP — агент может распаковать и обработать содержимое (если это поддерживает сценарий задачи)

**Не поддерживаются напрямую:** Google Docs, ODS и другие облачные форматы — сохраните файл как `.xlsx`, `.docx` или `.pdf` и прикрепите к задаче.

Обычный лимит — до **10 МБ** на одно вложение (администратор может изменить в настройках компании). При ошибке загрузки уменьшите файл или сожмите архив.

## Как передать файл агенту

1. Откройте **задачу** или **создайте новую**.
2. Нажмите **Прикрепить файл** в переписке задачи или в форме создания.
3. Выберите файл на компьютере.
4. Опишите, **что нужно сделать** — и нажмите **Запустить** агента.

![Блок вложений на задаче](/img/guides/issues/07-attachments.webp)

## Пример

Прикрепите **прайс-лист поставщика** в Excel и напишите: «Сравни цены с нашим прайсом и выдели позиции, где у них дешевле». Для работы с таблицей подключите [навык](/docs/cloud/skills) и вкладку **Office** — [Excel и PowerPoint](/docs/office/excel-pptx). На **Solo+** готовый файл — в **Результате** задачи.

## Как агент прикрепляет файл обратно

Файлы **от агента** появляются **автоматически** после завершения запуска:

1. Агент выполняет задачу.
2. Готовый файл попадает в блок **Результат** на задаче.
3. На **Solo+** — та же запись в [каталоге артефактов](./overview).

Вам не нужно ничего настраивать — достаточно открыть задачу и нажать **Скачать**.

<summary>Для разработчика: API вложений и work-product</summary>

Прикрепление агентом во время run:

1. `POST /api/companies/:companyId/issues/:issueId/attachments`
2. При необходимости — главный результат run: `POST /api/issues/:issueId/work-products` (тип `artifact`)

```bash
curl -sS -X POST \
  "$DATAGENT_API_URL/api/companies/$DATAGENT_COMPANY_ID/issues/$DATAGENT_TASK_ID/attachments" \
  -H "Authorization: Bearer $DATAGENT_API_KEY" \
  -H "X-Datagent-Run-Id: $DATAGENT_RUN_ID" \
  -F 'file=@"report.xlsx";type=application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
```

| Симптом | Что проверить |
| --- | --- |
| 413 | Лимит размера вложения |
| Файла нет в каталоге | Тариф **Solo+**, правильная компания |
| 403 | Ключ агента другой компании |
