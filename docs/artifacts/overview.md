# Каталог артефактов

:::info В разработке
Страница в очереди [DOC-PLAN-2026-Q3](/docs/meta/DOC-PLAN-2026-Q3) (Priority 2). Ниже — краткая выжимка для операторов.
:::

**Артефакты** — медиа-библиотека компании: изображения, видео, документы и файлы, которые агенты прикрепили к задачам. В панели: `/{префикс компании}/artifacts`.

## Зачем каталог

- Увидеть **все результаты** агентов в одном месте, не открывая каждую задачу
- Искать по имени, фильтровать по **типу** и **проекту**
- Группировать по **задаче** или родительской задаче
- Быстрый просмотр (Quick View) для image/video/document

## Фильтры в URL

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `kind` | all, image, video, document, text, file | all |
| `q` | поиск (debounce) | — |
| `groupBy` | none, task, parent_task | task |
| `groupIssueId` | drill-in в группу | — |
| `projectId` | UUID проекта | все проекты |

Состояние фильтров **сохраняется в адресной строке** — можно делиться ссылкой с коллегой.

## Типы превью

- **Изображения** — миниатюра в сетке, полный просмотр по клику
- **Видео** — poster в сетке, воспроизведение в Quick View (MP4, WebM, MOV)
- **Документы** — иконка и метаданные; скачивание
- Карточка: клик по превью → Quick View; по заголовку → **задача**

## Мобильная панель

На узком экране — отдельный picker типов и sheet с действиями. Пункт **Артефакты** не дублируется в нижней навигации доски (как и задумано в продукте).
