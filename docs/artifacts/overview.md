# Каталог артефактов

**Артефакт** — файл, который агент **создал или обработал** в ходе задачи: таблица, отчёт, изображение, презентация, документ. Всё хранится в карточке задачи и в **общей медиатеке** компании — откройте, посмотрите или **скачайте** одним действием.

Это **готовая функция** платформы: артефакты работают стабильно на [app.datagent.ru](https://app.datagent.ru) в каталоге `/{префикс компании}/artifacts`. Если нужен не текст в комментарии, а **файл на руки** — смотрите блок **Результат** на задаче и каталог артефактов.

> **Артефакты доступны на тарифе Solo и выше.**  
> На **Free** агент может описать результат текстом в задаче, но **не прикрепить файл** в медиатеку. [Тарифы →](/docs/cloud/pricing)

> **Каталог артефактов — только в десктопной версии** [app.datagent.ru](https://app.datagent.ru).  
> В мобильной нижней навигации пункта «Артефакты» нет; заголовок фильтров на телефоне **не закреплён** под хлебными крошками — удобнее открывать каталог с компьютера.

## Что даёт каталог

- **Соберите** все файлы агентов в одном месте — без обхода каждой задачи
- **Найдите** файл по имени, типу или проекту
- **Сгруппируйте** по задаче или родительской задаче
- **Откройте** предпросмотр для изображений, видео и документов

## Типы файлов

- **Изображения** — миниатюра в сетке, по клику полный просмотр
- **Видео** — постер в сетке, воспроизведение в окне просмотра (MP4, WebM, MOV)
- **Документы** — иконка и сведения; **скачать** одним действием
- По предпросмотру — быстрый просмотр; по заголовку карточки — переход к **задаче**

## Фильтры

Настройте вид каталога — адрес в браузере обновится, ссылку можно отправить коллеге.

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `kind` | all, image, video, document, text, file | all |
| `q` | поиск | — |
| `groupBy` | none, task, parent_task | task |
| `groupIssueId` | открыть одну группу | — |
| `projectId` | проект | все проекты |

## Как выглядит результат

Агент выполнил задачу — **файл появился в карточке задачи**. Нажмите **Скачать** или откройте прямо в браузере. Тот же файл виден в каталоге всей компании.
