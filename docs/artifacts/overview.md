# Каталог артефактов

> **Зачем:** Найти любой файл, который агенты прикрепили к задачам, — без обхода каждой карточки на доске.

**Артефакты** — общая медиатека компании на [app.datagent.ru](https://app.datagent.ru): `/{префикс компании}/artifacts`.

## Зачем каталог

- Собрать **все результаты** агентов в одном месте
- Найти файл по имени и отфильтровать по **типу** или **проекту**
- Сгруппировать по **задаче** или по родительской задаче
- Открыть **быстрый просмотр** (Quick View) для изображений, видео и документов

## Фильтры в URL

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `kind` | all, image, video, document, text, file | all |
| `q` | поиск (debounce) | — |
| `groupBy` | none, task, parent_task | task |
| `groupIssueId` | drill-in в группу | — |
| `projectId` | UUID проекта | все проекты |

Настроили фильтры — адрес в браузере обновится. Отправьте ссылку коллеге: он увидит тот же вид каталога.

## Типы превью

- **Изображения** — миниатюра в сетке, по клику полный просмотр
- **Видео** — постер в сетке, воспроизведение в Quick View (MP4, WebM, MOV)
- **Документы** — иконка и сведения о файле; скачивание одним действием
- По превью открывается Quick View; по заголовку карточки — переход к **задаче**

## Мобильная панель

На телефоне типы файлов выбираются отдельным списком, действия — в выезжающей панели. Пункт **Артефакты** намеренно не дублируется в нижней навигации доски — каталог открывается из меню компании.
