# Каталог артефактов

**Артефакт** — это файл, который агент **создал или обработал** в ходе задачи: таблица с данными, готовый отчёт, изображение, презентация, документ. Файлы хранятся в задаче и в **общей медиатеке** компании — их можно открыть, просмотреть и скачать.

Если вам нужен не текст в комментарии, а **готовый файл на руки** — смотрите блок **Результат** на задаче и каталог артефактов на [app.datagent.ru](https://app.datagent.ru): `/{префикс компании}/artifacts`.

> **Артефакты доступны на тарифе Solo и выше.**  
> На **Free** агент может описать результат текстом в задаче, но **не прикрепить файл** в медиатеку. [Тарифы →](/docs/cloud/pricing)

> **Раздел артефактов отображается только в десктопной версии** [app.datagent.ru](https://app.datagent.ru).  
> В мобильной нижней навигации доски пункта «Артефакты» нет — откройте каталог с компьютера через меню компании.

## Что даёт каталог

- **Соберите** все файлы агентов в одном месте — без обхода каждой задачи
- **Найдите** файл по имени, типу или проекту
- **Сгруппируйте** по задаче или родительской задаче
- **Откройте** быстрый просмотр для изображений, видео и документов

## Типы файлов

- **Изображения** — миниатюра в сетке, по клику полный просмотр
- **Видео** — постер в сетке, воспроизведение в окне просмотра (MP4, WebM, MOV)
- **Документы** — иконка и сведения; скачивание одним действием
- По превью — быстрый просмотр; по заголовку карточки — переход к **задаче**

## Фильтры

Настройте вид каталога — адрес в браузере обновится, ссылку можно отправить коллеге.

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `kind` | all, image, video, document, text, file | all |
| `q` | поиск | — |
| `groupBy` | none, task, parent_task | task |
| `groupIssueId` | открыть одну группу | — |
| `projectId` | проект | все проекты |
