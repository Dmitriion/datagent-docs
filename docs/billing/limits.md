# Лимиты по тарифам

Публично два тарифа. Цифры бесплатного совпадают с [карточками на datagent.ru](https://datagent.ru/#pricing). Условия Корпоративного задаёт договор.

:::info[Проверка лимитов]

Жёсткая проверка в API может включаться не сразу. Ориентир бесплатного тарифа: до 3 агентов и 100 запусков в месяц.

:::

## Сводка

| | **Бесплатный** | **Корпоративный** |
| --- | --- | --- |
| **Условия** | Бесплатно | Условия под вашу компанию |
| **Рабочие ИИ-компании** | 1 | по договору |
| **Агенты** | до 3 | по договору |
| **Запуски в месяц** | 100 | по договору |
| **Ключи к моделям** | свои (GigaChat, YandexGPT, OpenAI, Anthropic) | по договору |
| **Подтверждения** | очередь и журнал действий | расширенные подтверждения и готовые правила контроля |
| **Офис агентов** | демо-режим, без подключения агентов к чату | по договору |
| **Поддержка** | сообщество (Telegram, MAX) | по договору |
| **Установка** | облако | свои серверы, выделенный контур |
| **Роли и доступы** | не входят | входят |
| **Коннектор 1С** | не входит | входит |

Битрикс24, управление браузером, внешние инструменты, каталог файлов и чат с агентами в Офисе не входят в бесплатный тариф. Доступно на платных условиях, [уточните у нас](https://datagent.ru/#demo).

## Если запуски закончились

Новый запуск не стартует. Задача и переписка сохраняются. На бесплатном тарифе работа продолжится в начале следующего месяца.
