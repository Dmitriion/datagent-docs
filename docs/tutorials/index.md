# Практические сценарии

> **Зачем:** Перейти от «понял концепции» к **конкретному результату** — подключить CRM, собрать плагин, автоматизировать рутину на [app.datagent.ru](https://app.datagent.ru).

Здесь собраны **длинные walkthrough'ы** с кодом и чеклистами. Короткий старт — в [облачном гайде](/docs/cloud/getting-started); ежедневная работа — в [учебнике](/docs/guides/01-first-day).

## Когда какой материал читать

1. **Первый день в облаке** — [Первый агент за 5 минут](/docs/cloud/getting-started), затем [день 1 в учебнике](/docs/guides/01-first-day).
2. **Нужна CRM** — сценарий [automate-crm](/docs/tutorials/automate-crm) + [интеграция Bitrix24](/docs/integrations/bitrix24).
3. **Нужен свой инструмент** — [build-plugin](/docs/tutorials/build-plugin) и [плагины в облаке](/docs/cloud/plugins).
4. **Задачи, память, согласования** — [задачи](/docs/concepts/issues), [память](/docs/concepts/memory), [одобрения](/docs/concepts/approvals).
