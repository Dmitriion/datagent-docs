## Рекомендуемый порядок

1. [Старт в Cloud](/docs/cloud/getting-started) — компания, агент, первая задача.
2. [Первый агент](/docs/cloud/first-agent) — поля, навыки, типичные ошибки.
3. [Каталог интеграций](/docs/integrations/overview) — выберите сервис под вашу задачу.
4. Закрепите канал или CRM, если нужно — сценарий ниже.
5. При необходимости — [конвейеры](/docs/workflows/pipelines) и [тарифы](/docs/cloud/pricing).
