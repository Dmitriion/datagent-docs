Добро пожаловать в Datagent

Datagent — control plane для AI-агентов в компаниях: Board UI, API на server, исполнение run через heartbeat, LLM-адаптеры и плагины в child-process. Монорепозиторий (pnpm): server, ui, cli, packages/db, packages/adapters/*, packages/plugins/*. Данные — PostgreSQL (embedded или DATABASE_URL); память агентов и OAuth токены адаптеров — в БД instance, не в отдельном Runner-сервисе.

Документация для инженеров (развёртывание, API, плагины) и для владельцев бизнеса (сценарии интеграций без кода).

ШагРазделЧто получите

3Первый агентАгент gigachat_local / yandexgpt_local, wakeup, heartbeat run
4УчебникИстории для оператора и руководителя: Board, одобрения, Офис
5КонцепцииТермины, архитектура, как устроен heartbeat
6APIWakeup, runs, issues, plugins

Ключевые возможности​

  • Компании, агенты, issues — задачи и диалоги в Board; run через POST /api/agents/:id/wakeup и heartbeat-runs (публичного POST /api/runs нет).
  • LLM — GigaChat (gigachat_local, OpenCode + OAuth), YandexGPT (yandexgpt_local, IAM + folderId), универсальный OpenCode (opencode_local).
  • Плагины — tools и jobs в отдельных worker-процессах (PluginWorkerManager); установка через Plugin Manager / datagent plugin install.
  • Bitrix24 — imbot bridge: polling bitrix-poll, binding агента, ответы в чат (без CRM tools bitrix24_* в manifest).
  • Телеграм — плагин Telegram Datagent: long poll getUpdates, уведомления, апрувы Board, inbound в issues.
  • Учебник — работа с платформой: восемь глав и шпаргалка; Board, одобрения и Офис без «чата без памяти».
  • BrowserBridge — локальный демон datagent-bridge и plugin tools datagent.browserbridge:browser_* (tunnel с server).
  • Офис и документы — пространство «Офис» (Operator View), 1С Коннектор (MCP proxy), Office Plugin (Excel / Word / PPTX через OfficeCLI).

Архитектура в двух словах​

Один HTTP-процесс на PORT (по умолчанию 3100): API /api/* и Board на том же origin в dev (SERVE_UI=false + Vite middleware). Отдельного Board на :3200, Redis/BullMQ для run и пакета packages/core нет.
