## Коротко о цикле

1. **Задача** — место, где живёт поручение, переписка и файлы.
2. **Запуск** — агент начинает работу по кнопке, расписанию или сообщению из канала.
3. **Данные и инструменты** — только то, что открыл администратор.
4. **Результат** — ответ и материалы в задаче; при необходимости — запрос на согласование.

## Кто может запустить агента

| Источник | Когда это удобно |
| --- | --- |
| В панели | Разовые поручения и проверка сценария |
| Регламент | Утренние сводки и регулярные проверки |
| Канал связи | Сообщение в Телеграм или Битрикс24 превращается в задачу |
| Коллега с правами | Совместная работа в одной компании |

Каждый цикл — отдельный **запуск** с лимитом тарифа. Подробнее о квотах — в [тарифах](/docs/cloud/pricing).

<h2 id="connection-security">Интеграции и доступ к данным</h2>

Подключённые сервисы (МойСклад, маркетплейсы, CRM, облако и др.) открываются агенту через **Настройки → Интеграции** и вкладку **Подключения** у агента.

- Секреты хранятся в компании, не в тексте задачи.
- Готовые Russia-коннекторы — **только чтение**.
- Агент не получает доступ «ко всему аккаунту» без явного выбора подключений.

Каталог: [интеграции](/docs/integrations/overview).

## Что видит оператор

| В панели | Зачем |
| --- | --- |
| Задача | Поручение, комментарии, результат |
| Журнал запуска | Последовательность шагов агента |
| Согласования | Решения по рискованным действиям |
| Агенты и подключения | Кому что разрешено |

## Ключевые факты

- Работа строится вокруг **задачи** и **запуска**, а не бесконечного чата.
- Агент использует только **разрешённые** данные и инструменты.
- Рискованные действия можно вынести в **согласование**.
- Cloud работает в браузере на [app.datagent.ru](https://app.datagent.ru).
