# Память агента

Без памяти каждый запуск — с чистого листа: снова объяснять, как вы отвечаете клиентам, какие продукты продаёте, что уже решили на прошлой неделе. **Память** в Datagent хранит это **между задачами** — не в личном чате с нейросетью, а в **вашей компании**, под вашим контролем.

Это не поиск в интернете — только то, что вы сами разрешили сохранить. Агент одной компании **не видит** память другой.

## Пример: поддержка в Битрикс24

**Было поручение:** «Ответь клиенту по возврату — вежливо, на «вы», без обещания срока без согласования с складом».

**Что помнит агент из памяти:** тон «вы», запрет обещать даты отгрузки, шаблон эскалации на склад.

**Что сделал агент:** черновик ответа в задаче с учётом правил.

**Результат:** вы правите одну фразу и отправляете — не переписываете инструкцию с нуля. После успешного диалога вывод «клиент спрашивал про возврат партии B» может сохраниться для следующих обращений.

## Что агент помнит автоматически

| Тип | Простыми словами |
| --- | --- |
| **Правила** | Тон, запреты, шаблоны ответов |
| **Факты** | Продукты, процессы, контакты |
| **Выводы после работы** | Итоги успешных запусков |
| **Справочник** | Подключённая документация |

Перед запуском агент получает нужные фрагменты; после — система может **сохранить** новое — если это включено в политике.

На **Free** — **50 МБ**; на платных тарифах больше — [тарифы](/docs/cloud/pricing).

## Как управлять памятью вручную

### Память компании

1. **Память компании** в меню или настройках.
2. **Привязки** — какие хранилища подключены.
3. **Политика** — сколько контекста давать агенту, правила записи.
4. **Обслуживание** — экспорт, заморозка при аудите.

### Память агента

**Агент** → вкладка **Память**:

| Вкладка | Для чего |
| --- | --- |
| **Обзор** | Быстрый старт |
| **Слои** | Что подключено этому агенту |
| **Контекст** | Проверить, что увидит агент перед запуском |
| **Здоровье** | Объём и предупреждения |
| **Аудит** | Откуда взялась запись |
| **Админ** | Заморозка и обслуживание |

Нет слоёв — **создать привязки по умолчанию** и проверьте на одной задаче.

## Управление памятью [Studio+]

На тарифах **Studio** и **Business** работает **автоматическая чистка памяти**: убирает устаревшее, сжимает дубликаты, помечает спорное на проверку. Вам не нужно вручную чистить тысячи записей.

| Тариф | Авточистка |
| --- | --- |
| Free, Solo | нет |
| **Studio**, Business | да |

Настройки — **Память компании → Обслуживание** и **Админ** у агента.

## Память и Битрикс24

Память **не заменяет CRM**. Сделки — в **Битрикс24**. Datagent помнит **как агент должен работать** и **что выяснили в задачах**.

## Частые вопросы

**Помнит всё навсегда?**  
Нет — политика и авточистка ограничивают объём и срок.

**Стереть ошибочную запись?**  
Да — «забыть» или «исправить» в интерфейсе памяти (права администратора).

**Нужен программист?**  
Нет для старта — привязки по умолчанию и одна пробная задача.
