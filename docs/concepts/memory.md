# Память агента

**Память** — то, что агент **запоминает** между задачами: правила компании, важные факты, прошлые выводы, предпочтения команды. Это **не** поиск по интернету и **не** копия личного чата с нейросетью — только то, что вы сами разрешили сохранить в компании.

Память привязана к **компании**: агент одной организации не видит данные другой.

## Что агент помнит автоматически

| Тип | Простыми словами |
| --- | --- |
| **Правила и политики** | Тон общения, запреты, шаблоны ответов |
| **Факты по компании** | Продукты, процессы, контакты |
| **Выводы после запуска** | Итоги успешной работы — для следующих задач |
| **Справочник** | Подключённая документация (wiki) |

Перед **запуском** агент получает релевантные фрагменты из разрешённых **слоёв**. После запуска система может **сохранить** новые записи — если это включено в политике компании.

На **Free** — базовая память (**50 МБ**); на платных тарифах объём больше — см. [тарифы](/docs/cloud/pricing).

## Как управлять памятью вручную

### Память компании

1. Откройте **Память компании** в меню (или из настроек компании).
2. **Привязки** — какие хранилища подключены к организации.
3. **Политика** — сколько контекста подмешивать перед запуском, правила записи после работы.
4. **Обслуживание** — очередь обработки, экспорт, заморозка записи при аудите.

### Память конкретного агента

Откройте **Агента** → вкладка **Память**. Вкладки в панели:

| Вкладка | Для чего |
| --- | --- |
| **Обзор** | Статус слоёв и быстрый старт |
| **Слои** | Какие слои подключены этому агенту |
| **Контекст** | Проверить, что увидит агент перед запуском |
| **Здоровье** | Объём, предупреждения, тренды |
| **Аудит** | Откуда взялись записи |
| **Админ** | Заморозка, политика, обслуживание (для администраторов) |

Если слоёв ещё нет — нажмите **создать привязки по умолчанию** и проверьте на одной задаче.

**Заморозка** временно запрещает новые записи (инцидент, миграция данных). **Спорные фрагменты** можно пометить на проверку человеком.

## Садовник — автоматическая чистка памяти [Studio+]

**Садовник** (Gardener) — фоновая служба, которая **убирает устаревшее**, сжимает дубликаты и помечает спорное на проверку. Вам не нужно вручную чистить тысячи записей.

| Тариф | Садовник |
| --- | --- |
| Free, Solo | нет |
| **Studio**, Business | да |

Настройки политики и превью обслуживания — в **Память компании → Обслуживание** и на вкладке **Админ** у агента.

:::note Для администраторов
Полный контракт памяти — в спецификации продукта (§22 memory). REST и MCP — [обзор API](/docs/api-reference/overview) (раздел памяти в разработке в справке).
:::

## Память и Битрикс24

Память **не заменяет CRM**. Сделки — в **Битрикс24**. Datagent помнит **как агент должен работать** и **что выяснили в задачах** — удобно в паре с [GigaChat](/docs/integrations/gigachat) и [каналами](/docs/guides/06-channels).

## Частые вопросы

**Агент помнит всё навсегда?**  
Нет — политика и садовник ограничивают объём и срок жизни записей.

**Можно стереть ошибочную запись?**  
Да — через интерфейс памяти (забыть / исправить), с правами администратора.

**Нужен ли программист для старта?**  
Нет — создайте привязки по умолчанию и проверьте на одной задаче.
