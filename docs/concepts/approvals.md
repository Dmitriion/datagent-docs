# Согласования в Datagent — контроль перед важным действием агента

> **Зачем:** Чтобы агент **сам делал рутину**, но **не отправлял письмо, не менял файл и не нажимал кнопку на сайте** без вашего «да». **Datagent** останавливает run и показывает запрос в разделе **Согласования**.

**Согласование** (approval) — это пауза: агент дошёл до шага, который вы заранее считаете рискованным, и ждёт решения человека в панели (дублируется в **Телеграм**, если настроено).

## Это работает так

1. Агент в задаче вызывает инструмент — например, изменить таблицу или действие в браузере.
2. Плагин помечает шаг как **требующий одобрения**.
3. В **Согласованиях** появляется карточка: что хотят сделать, к какой задаче привязано.
4. Вы читаете контекст, жмёте **Одобрить** или **Отклонить**.
5. После одобрения run **продолжается**; после отклонения — рискованный шаг не выполняется.

Типичный сценарий: агент готовит план правок в Excel → вы проверяете → только потом изменения применяются к файлу.

## Когда срабатывает

| Ситуация | Пример |
| --- | --- |
| Изменение документа | План правок в `.xlsx` перед применением |
| Браузер | Опасное действие на сайте (`browser_action`) |
| Свой плагин | Явный запрос `request_board_approval` в manifest |

Обычные ответы в переписке задачи **без** изменения внешних систем согласование не требуют.

## Как это выглядит в панели

1. Откройте **Согласования** в меню (или значок с числом непрочитанных).
2. Выберите запрос — увидите тип, описание и ссылку на **задачу**.
3. При необходимости откройте задачу: вложения, переписка, журнал запуска.
4. Примите решение кнопками **Одобрить** / **Отклонить**.

![Кнопки решения](/img/guides/approvals/03-actions.webp)

На телефоне та же очередь доступна в адаптивной вёрстке; источник правды — панель на [app.datagent.ru](https://app.datagent.ru), не личный чат.

:::tip Доступно бесплатно
Согласования работают на **Free** — это часть control plane, не отдельная опция.
:::

## Телеграм

Если администратор настроил бот уведомлений, запрос может прийти в чат с кнопками. Решение всё равно фиксируется в панели и привязано к задаче. Подробнее: [Телеграм](../integrations/telegram).

## Частые вопросы

**Обязательно ли одобрять каждый ответ клиенту?**  
Нет. Согласование — только для **рискованных** инструментов, не для обычного текста в задаче.

**Что если долго не отвечать?**  
Run ждёт вашего решения. Договоритесь в команде про SLA на очередь согласований.

**Можно отключить согласования?**  
Рискованные плагины рассчитаны на governance. Полная автономия без контроля — не целевой режим Datagent.

**Кто может одобрять?**  
Пользователи с правами оператора / board в вашей компании.
