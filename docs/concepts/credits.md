# Как работают кредиты в Datagent — кошелёк и экономика запусков

> **Зачем:** Спланировать бюджет на AI-агентов — не гадать после счёта. **Datagent** списывает **кредиты** за каждый **запуск**, а **тариф** ограничивает число агентов и run в месяц на [app.datagent.ru](https://app.datagent.ru).

**Кредиты** — внутренняя валюта платформы. **Подписка** (Free / PRO / Business) — сколько агентов и запусков вам **разрешено**. Обе оси действуют **одновременно**.

## Это работает так

1. У компании есть **кошелёк** с остатком кредитов (личный кабинет / настройки компании).
2. Вы нажимаете **Запустить** — начинается **run** (см. [heartbeat](./heartbeat)).
3. По ходу run списываются кредиты: вызовы **GigaChat**, инструменты, длинный контекст.
4. Run завершился — в журнале видно, что произошло; остаток кошелька обновился.
5. Если кредиты **закончились** — новые run **не стартуют**, пока не пополните кошелёк (когда оплата будет в продукте).
6. Если исчерпан **лимит тарифа** (например 100 run на Free) — новые run блокируются по правилам подписки.

:::info Оплата в продукте
Пополнение кошелька и автооплата подписки **в разработке** (ЮKassa). Лимиты таблицы — целевые; проверка может быть мягкой до релиза биллинга.
:::

## Три «счётчика» — не путать

| Счётчик | Кто задаёт | Что ограничивает |
| --- | --- | --- |
| **Кредиты** | Тариф + пополнение кошелька | Стоимость **работы** агентов |
| **Запуски / месяц** | Тариф Free / PRO / Business | Сколько **run** можно сделать |
| **Бюджет токенов** | Вы в настройках компании/агента | Расход на **API нейросети** (hard-stop) |

Пример: на **PRO** есть право на 2 000 run, но **пустой кошелёк** — run не пойдёт. И наоборот: на **Free** кредиты есть, но **101-й run** в месяц упрётся в тариф.

## Экономика простыми примерами

Точная формула списания зависит от сборки биллинга. Для **планирования** используйте порядок величин:

| Сценарий | Что происходит | Ориентир по «тяжести» |
| --- | --- | --- |
| Короткий ответ в задаче | 1–2 вызова GigaChat, без tools | Лёгкий run |
| Диалог **Битрикс24** | Несколько вызовов модели + комментарии в задаче | Средний run |
| Run с **Excel** на задаче | Модель + tools таблицы, возможно [согласование](./approvals) | Тяжелее |
| Run с **браузером** (PRO) | Много шагов + скриншоты | Тяжёлый run |

**Практика:** после недели пилота откройте журнал 10 типичных диалогов и оцените средний расход — так проще обосновать **PRO** или **Business**.

### Пример: линия поддержки в CRM

- **1 агент** на GigaChat, **Битрикс24**, ~200 диалогов в месяц.
- На **Free** не влезете в 100 run — нужен **PRO** по лимиту run.
- Кредиты: заложите запас на пиковые дни; длинные переписки стоят дороже коротких «да/нет».

### Пример: внутренний помощник

- **1 агент**, задачи из панели, без CRM, ~30 run в месяц.
- Часто укладывается в **Free** по run; кредиты — по факту длины ответов.

## Ключи GigaChat / YandexGPT — отдельно

**Datagent** берёт **кредиты за платформу** (запуски, control plane).

**Сбер** и **Yandex Cloud** тарифицируют **вызовы модели** по своим прайсам — это **ваши** ключи и ваш договор с провайдером.

Итого в бюджете две строки:

1. Подписка **Datagent** (PRO / Business) + **кредиты** кошелька.
2. Счёт **GigaChat** / **YandexGPT** у провайдера.

## Как контролировать расход

1. **Тариф** — не держите 10 агентов, если работают 2 ([тарифы](../cloud/pricing)).
2. **Кошелёк** — следите за остатком в кабинете (после запуска биллинга).
3. **Бюджет токенов** — лимит на стоимость LLM в настройках компании.
4. **Согласования** — меньше рискованных auto-действий → меньше лишних run.
5. **Журнал** — разбор «дорогих» run раз в неделю.

## Частые вопросы

**Что будет, когда кончатся кредиты?**  
Новые **запуски** не начнутся. Пополните кошелёк (когда будет доступно в UI).

**Кредиты переносятся на следующий месяц?**  
Правила переноса опубликуем с запуском биллинга; пока ориентируйтесь на остаток в кабинете.

**Free хватает на Битрикс24?**  
На **пилот** — да. На постоянную линию с сотнями диалогов — обычно **PRO**.

**PRO отменяет кредиты?**  
**Нет.** PRO даёт **лимиты и BrowserBridge**; run всё равно **тратят кредиты**.

**Можно ли платить только кредитами без PRO?**  
На **Free** — с лимитом 3 агента / 100 run. Функции **PRO** (браузер) без подписки недоступны.
