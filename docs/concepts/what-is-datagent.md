# Что такое Datagent

Datagent — платформа, где вы создаёте ИИ-агентов, даёте им задачи и следите за их работой через обычный веб-интерфейс на [app.datagent.ru](https://app.datagent.ru).

Агент — не чат-бот. Он не просто отвечает на вопросы, а самостоятельно выполняет работу: собирает данные, заполняет документы, отвечает клиентам, делает отчёты. Вы контролируете каждый шаг.

## Из чего состоит Datagent

**Агент** — исполнитель. Получает задачу, работает, отчитывается результатом.

**Задача** — что нужно сделать. Разовая или повторяющаяся по расписанию.

**Канал** — откуда приходят задачи: Телеграм, Битрикс24, панель Datagent.

**Одобрение** — момент, когда вы решаете: разрешить агенту следующий шаг или остановить.

**Навык** — готовый набор инструментов для агента. Устанавливается из каталога за пару кликов.

## Пример из практики

Менеджер по продажам создаёт агента «Аналитик». Каждый понедельник агент собирает данные из CRM, считает конверсию, формирует отчёт в Excel и отправляет его в Телеграм-канал команды. Менеджер только проверяет результат.

## Как это выглядит в других сценариях

**Просроченные сделки из Битрикс24**  
Задача: «собери сделки без активности больше 7 дней». Агент запрашивает CRM, собирает таблицу в задаче. Вы решаете, кому из менеджеров отправить напоминание.

**Входящие в мессенджере**  
Клиент пишет в Телеграм или в линии Битрикс24. Агент готовит черновик ответа. Перед отправкой — [одобрение](./approvals): вы нажимаете «Да» или правите текст.

## Что нужно для начала

Регистрация бесплатная: на **Free** — одна компания, до трёх агентов и сто runs в месяц.

Пошагово: [Как начать за 5 минут](../cloud/getting-started) → [Первый агент](../cloud/first-agent).

## Для кого подходит каждый тариф

| Тариф | Кому |
| --- | --- |
| **Free** | Попробовать гипотезу: один проект, пара агентов, короткий пилот |
| **Solo** | Один человек ведёт серьёзную работу каждый день: артефакты, учёт затрат, без лимита на число агентов в компании |
| **Studio** | Команда: BrowserBridge, Битрикс24, бюджеты, до трёх компаний |
| **Business** | Компания с ролями, коннектором 1С, десятью проектами и высоким потолком runs |
| **Enterprise** | Свой сервер, договорной SLA |

Цены и лимиты — на [странице тарифов](../cloud/pricing).

## Чем Datagent не является

- Не чат «спроси у бота» без журнала и контроля.
- Не замена CRM или 1С — работа **поверх** них.
- Не установка в ваш ЦОД по умолчанию — основной путь **облако**; свой сервер — **Enterprise**.

:::info BrowserBridge — от Studio
Управление браузером и полный плагин Битрикс24 — с тарифа **Studio** и выше. [Тарифы →](../cloud/pricing)
:::

## Частые вопросы

**Нужен ли программист для старта?**  
Нет. Первого агента настраивают в браузере за 5–15 минут.

**Что будет, когда кончатся runs по тарифу?**  
Новые запуски не стартуют до нового месяца или смены тарифа. Подробнее — [Runs и лимиты](./credits).
