# Что такое Datagent

**Datagent** — это команда агентов, которым можно поручать задачи. Вы формулируете работу в панели на [app.datagent.ru](https://app.datagent.ru), агент подключается к нужным сервисам, выполняет шаги в фоне и возвращает результат в задачу. Журнал запусков, согласования перед риском и связка с Битрикс24 и российскими моделями — в одном месте, без личных чатов с нейросетью.

## Как это выглядит на практике

**Просроченные сделки из Битрикс24**  
Вы ставите задачу: «собери сделки без активности больше 7 дней». Агент запрашивает CRM, собирает таблицу в задаче. Вы проверяете и решаете, кому из менеджеров отправить напоминание.

**Входящие в мессенджере**  
Клиент пишет в Telegram или в линии Битрикс24. Агент готовит черновик ответа по вашим правилам. Перед отправкой — [согласование](./approvals): вы нажимаете «Да» или правите текст.

**Выгрузка из 1С для отчёта**  
Инженер настраивает коннектор 1С (тариф **Business** и выше). Агент по запросу подтягивает нужные данные, оформляет таблицу или черновик документа — не «проводит документ» в учёте без отдельной разработки.

## Что нужно для начала

Достаточно **аккаунта** на [app.datagent.ru](https://app.datagent.ru). Регистрация бесплатная: на **Free** — одна компания, до трёх агентов и сто запусков в месяц.

Пошагово: [Как начать за 5 минут](../cloud/getting-started) → [Первый агент](../cloud/first-agent).

## Для кого подходит каждый тариф

| Тариф | Кому |
| --- | --- |
| **Free** | Попробовать гипотезу: один проект, пара агентов, короткий пилот |
| **Solo** | Один человек ведёт серьёзную работу каждый день: артефакты, учёт затрат, без лимита на число агентов в компании |
| **Studio** | Команда в общем пространстве: BrowserBridge, Битрикс24, бюджеты, до трёх компаний |
| **Business** | Комания с ролями, коннектором 1С, десятью проектами и высоким потолком запусков |
| **Enterprise** | Свой сервер, договорной SLA, белая метка |

Цены и лимиты — только на [странице тарифов](../cloud/pricing).

## Чем Datagent не является

- Не чат-бот «на коленке» в мессенджере без журнала и контроля.
- Не замена CRM или 1С — работа **поверх** них через интеграции.
- Не установка в ваш ЦОД по умолчанию — основной путь **облако**; свой сервер — **Enterprise**.

## Основные термины

| Термин | Значение |
| --- | --- |
| **Агент** | Роль: модель + инструменты + правила |
| **Задача** | Тема работы: переписка, файлы, история запусков |

## Частые вопросы

**Нужен ли программист для старта?**  
Нет. Первого агента настраивают в браузере за 5–15 минут.

**Datagent — это свой сервер?**  
По умолчанию — **облако** на app.datagent.ru. Свой сервер — **Enterprise**, [заявка](../cloud/on-premise).

**Что будет, когда кончатся запуски по тарифу?**  
Новые run не стартуют до нового расчётного периода или смены тарифа. Подробнее — [Запуски и лимиты](./credits).

**Чем лучше просто ChatGPT?**  
Журнал по шагам, задачи на команду, согласования, Битрикс24 и лимиты по тарифу — не один общий чат.

:::note Для инженеров
Панель и API на одном origin. Запуск агента: `POST /api/agents/:id/wakeup`, журнал: heartbeat-runs. Адаптеры: `gigachat_local`, `yandexgpt_local`, `opencode_local`. [Архитектура](./agent-architecture.md), [Обзор API](../api-reference/overview.md).
:::
