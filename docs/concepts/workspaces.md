# Рабочие пространства

Задача «почини тесты в репозитории» — это не чат, а **код, git и команды**. Для таких поручений в Datagent есть **рабочее пространство**: изолированная среда, где агент работает как на отдельной машине под задачу.

Ответить клиенту в Битрикс24 или собрать сводку в Excel — **без** рабочего пространства, обычной задачи достаточно.

## Пример

Инженер ставит задачу: «Исправь падающий тест в ветке `fix/login`». Агент получает **среду проекта** с клоном репозитория, запускает тесты, коммитит правку. Оператор поддержки при этом **не видит** кнопку среды — его задачи по CRM идут без git.

## Два уровня

| Уровень | Что это | Аналогия |
| --- | --- | --- |
| **Пространство проекта** | Шаблон среды у [проекта](./projects): откуда выполняется код, секреты, политика | «Какой сервер у отдела» |
| **Среда на время задачи** | Живой экземпляр на один запуск или задачу | «Временная машина под эту ветку» |

## Это работает так

1. В **проекте** настраиваете пространство — окружение и политику.
2. Агент берёт задачу с привязкой к проекту; при запуске создаётся или переиспользуется среда.
3. Агент работает в среде: git, shell, файлы — по политике проекта.
4. Когда **задача завершена**, среда **закрывается** (или остаётся для повторного использования — по политике). Артефакты остаются в [каталоге](/docs/artifacts/overview).

:::info Облако
На [app.datagent.ru](https://app.datagent.ru) часто используют **изолированную среду** (песочницу) или SSH. Свой сервер — [тариф Enterprise](/docs/cloud/on-premise).
:::

## Изолированная среда [Studio+]

Агент работает в **отдельном контуре** — без доступа к остальным данным компании вне разрешённого.

**Подключение своей инфраструктуры** — свой хост или кластер под среду агента — с тарифа **Studio**.

| Тариф | Изолированная среда / своя инфраструктура |
| --- | --- |
| Free, Solo | нет |
| **Studio**, Business | да |

Настройка — карточка **проекта**, [ключи доступа](./secrets).

## Что настраивают в проекте

- **Окружение** — локальный хост, SSH или изолированная среда.
- **Ключи доступа** — репозиторий и API, не в тексте задачи.
- **Сервисы** — при необходимости поднять тестовую БД или mock API из панели проекта.
- **Политика** — можно ли переиспользовать среду между запусками, когда закрывать после завершения задачи.

Рискованные команды могут требовать [подтверждения](./approvals).

## Частые вопросы

**Где кнопка среды в задаче?**  
Появляется, когда проект с настроенным пространством и задача требует выполнения кода.

**Чем отличается от управления браузером?**  
BrowserBridge — браузер на **вашей** станции (**Studio+**). Пространство — **файлы и shell** в среде проекта.

**Проект без пространства?**  
Нормально. Большинство сценариев Битрикс24 и GigaChat обходятся без него.
