# Рутины

:::info В разработке
Страница в очереди [DOC-PLAN-2026-Q3](/docs/meta/DOC-PLAN-2026-Q3) (Priority 1).
:::

**Рутина** — правило «запускать агента по расписанию» без ручного нажатия **Запустить**: ежедневный отчёт, проверка inbox, синхронизация CRM.

## Что будет на этой странице

- Создание и редактирование рутины в панели компании
- Cron-выражения и часовой пояс instance
- Связь рутины с **агентом** и шаблоном **задачи**
- Отличие от **heartbeat** (внутренний цикл run) и от **wakeup** по API
- Лимиты тарифа и остановка при исчерпании credits
- Типовые сценарии: утренний дайджест, еженедельный отчёт

## Источники в продукте

- `server/src/routes/routines.ts`, `server/src/services/cron.ts`
- Миграции `0054+` (routines schema)
- `doc/ARCHITECTURE.md` — automation / scheduled execution
