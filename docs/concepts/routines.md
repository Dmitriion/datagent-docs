# Рутины

:::info В разработке
Полная статья о рутинах готовится — см. [план документации на Q3](/docs/meta/DOC-PLAN-2026-Q3).
:::

**Рутина (routine)** избавляет от ручного «Запустить» каждый день: вы задаёте расписание, и агент сам просыпается — для утреннего отчёта, проверки inbox или синхронизации с CRM.

## Что будет на этой странице

- Создать и отредактировать рутину в настройках компании
- Настроить расписание (cron) и часовой пояс вашего instance
- Привязать рутину к **агенту** и шаблону **задачи**
- Понять разницу с **heartbeat** (внутренний цикл run) и **wakeup** по API
- Учесть лимиты тарифа и остановку при нехватке credits
- Подсмотреть типовые сценарии: дайджест по утрам, отчёт раз в неделю

## Источники в продукте

- `server/src/routes/routines.ts`, `server/src/services/cron.ts`
- Миграции `0054+` (routines schema)
- `doc/ARCHITECTURE.md` — automation / scheduled execution
