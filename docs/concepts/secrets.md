# Ключи доступа компании

Ключ **GigaChat**, JSON для **Yandex Cloud**, webhook **Битрикс24** — нельзя вставлять в текст задачи: они попадут в журнал и увидят лишние люди. В Datagent для этого есть **ключи доступа** (секреты): зашифрованное хранилище в **Настройки компании → Секреты**.

Вы видите **имя** ключа, не сам пароль в открытом виде.

## Это работает так

1. Откройте **Настройки компании → Секреты** на [app.datagent.ru](https://app.datagent.ru).
2. Нажмите **Создать** — имя, тип, значение (вводится один раз).
3. В форме **агента** или **плагина** выберите ключ вместо вставки в текстовое поле.
4. Перед запуском платформа **подставит** значение в окружение модели (например, ключи GigaChat или JSON сервисного аккаунта Yandex).
5. При смене ключа обновите секрет — агенты подхватят новое значение без правки задач.

:::warning[Не кладите ключи в задачу]
Ключи в описании задачи попадут в **журнал запуска** — храните их только в разделе секретов.
:::

## Типичные секреты

| Секрет | Зачем |
| --- | --- |
| **GigaChat** | Идентификатор и секрет OAuth Сбера; токен кэширует платформа |
| **YandexGPT** | JSON ключа сервисного аккаунта + каталог (`folderId`) в настройках агента |
| **Плагины** | Webhook Битрикс24, токены ботов |
| **Браузер** | Параметры локальной службы управления браузером (**Studio+**) |

Инструкции: [GigaChat](/docs/integrations/gigachat), [YandexGPT](/docs/integrations/yandexgpt).

## Действия в панели

| Действие | Где |
| --- | --- |
| Создать | Настройки компании → Секреты → Новый |
| Привязать к агенту | Карточка агента → поля окружения / секреты |
| Привязать к плагину | Настройки плагина в менеджере плагинов |
| Ротировать | Карточка секрета → обновить значение |

Доступны **импорт** и журнал обращений к секрету (кто и когда использовал) — для аудита.

## Кто может управлять

**Администратор** и **владелец** компании. Агент по API-ключу **не** видит список секретов — только получает разрешённые значения во время своего запуска.

## Частые вопросы

**Секрет пропал из формы агента?**  
Проверьте, что секрет не удалён; пересохраните агента.

**Нужен ли секрет на Free?**  
Да, для GigaChat/Yandex — ключи провайдера обязательны на **любом тарифе**; храните их как секреты.

**Это то же самое, что ключ агента Datagent?**  
Нет. **Ключ агента** — для вызова API Datagent. **Секрет** — для GigaChat, CRM и т.д. **внутри** запуска.
