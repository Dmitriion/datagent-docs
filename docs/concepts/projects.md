# Проекты

Когда задач десятки, нужен **проект** — папка для направления: «Продажи», «Внедрение», «Поддержка». Внутри — связанные **задачи**, файлы и отчёты по расходу, без смешивания с другими отделами.

**Задача** — одно поручение агенту: «Сводка за май», «Ответ по сделке №123». Может быть без проекта — для разовых дел.

## Пример

Отдел продаж ведёт направление «Внедрение 2026»: десятки задач по клиентам, отчёты в [артефактах](/docs/artifacts/overview) и лимит расхода 50 000 ₽ в месяц. Разовый запрос «ответить на письмо» остаётся **без проекта** — не засоряет портфель.

## Это работает так

1. **Создайте проект** — название и описание в панели на [app.datagent.ru](https://app.datagent.ru).
2. При создании **задачи** или **регламента** укажите проект — работа попадёт в портфель.
3. В [каталоге артефактов](/docs/artifacts/overview) отфильтруйте по проекту — только файлы этого направления.
4. В отчётах по **расходам** смотрите затраты по проекту — см. [бюджеты](./budgets).

## Где в панели

| Место | Что даёт |
| --- | --- |
| **Проекты** | Список портфелей, настройки, пауза |
| **Форма задачи** | Поле «Проект» |
| **Артефакты** | Фильтр по проекту |
| **Офис** | «Комнаты» на карте — [обзор Офиса](/docs/office/overview) |

## Бюджет и пауза

У проекта может быть **месячный лимит расхода** (в рублях). При превышении платформа ставит проект на паузу — новые запуски по задачам проекта блокируются, пока оператор не разберёт [бюджетный инцидент](./budgets).

:::warning[Два разных лимита]
**Запуски агента в месяц** — квота тарифа (Free, Solo, …). **Бюджет проекта** — потолок расхода в рублях на направление. См. [Запуски и лимиты](./credits) и [бюджеты](./budgets).
:::

## Среда выполнения (для задач с кодом)

Для задач с репозиторием и кодом у проекта настраивают **рабочее пространство** — изолированную среду с git и shell. Оператору CRM чаще достаточно задачи без среды — см. [Рабочие пространства](./workspaces).

## Связь с целями

**Цель** — долгосрочный ориентир (квартал, OKR); проекты и задачи могут ссылаться на цель — [цели](./goals).

## Частые вопросы

**Обязателен ли проект?**  
Нет — используйте, когда команда делит портфель.

**Перенести задачу в другой проект?**  
Да — измените поле «Проект» в карточке задачи.

**Битрикс24 и проект?**  
В настройках бота можно указать проект — чаты CRM создают задачи в нужном портфеле — [Битрикс24](/docs/integrations/bitrix24) (**Studio+**).
