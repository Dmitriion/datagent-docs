# Проекты

> **Зачем:** Разделить работу по направлениям — «Продажи», «Внедрение», «Маркетинг» — и видеть задачи, расход и файлы в одном контуре.

**Проект** — контейнер внутри компании: к нему привязывают **задачи**, **рутины**, **артефакты** и иногда **execution workspace** (среду выполнения кода агента). На [app.datagent.ru](https://app.datagent.ru) проекты видны в доске, в «Офисе» (комнаты = проекты) и в фильтрах каталога.

## Это работает так

1. Создаёте проект — название, описание, при необходимости политика среды.
2. При создании задачи или рутины указываете **project** — она попадает в портфель.
3. В [каталоге артефактов](/docs/artifacts/overview) фильтруете по `projectId` — только файлы этого направления.
4. В отчётах по **расходам** смотрите затраты по проекту — см. [бюджеты](./budgets).

Задача может существовать **без** проекта — это нормально для мелких поручений.

## Где в панели

| Место | Что даёт |
| --- | --- |
| **Доска / проекты** | Список портфелей, настройки, пауза |
| **Форма задачи** | Поле «Проект» при создании |

## Бюджет и пауза

У проекта может быть **месячный лимит расхода** (в копейках). При **hard-stop** платформа ставит проект на паузу — новые run по задачам проекта блокируются, пока оператор не разберёт [бюджетный инцидент](./budgets).

:::warning Не путать с кредитами тарифа
**Кредиты** — кошелёк и лимит run по подписке Free/PRO. **Бюджет проекта** — потолок расхода внутри компании на это направление.
:::

## Execution workspace (кратко)

Для задач с кодом и репозиторием у проекта настраивают **workspace** — привязку к среде (локально, SSH, sandbox), секретам и runtime-сервисам. Это путь для инженеров и агентов-разработчиков; оператору CRM чаще достаточно задачи без workspace.

Полная справка по workspace — в плане документации Q3 (`concepts/workspaces`).

## Связь с целями

**Цель (goal)** — долгосрочный ориентир OKR; задачи и проекты могут ссылаться на цель. Цели появятся в отдельной странице справки.

## Частые вопросы

**Обязателен ли проект?**  
Нет. Используйте, когда команда реально делит портфель.

**Можно ли перенести задачу между проектами?**  
Да, измените проект в карточке задачи (если права позволяют).

**Bitrix24 и проект?**  
В связке бота можно указать project — чаты CRM создают задачи в нужном портфеле — [Bitrix24](/docs/integrations/bitrix24).
