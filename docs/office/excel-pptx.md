# Excel и PowerPoint на задаче

Агент умеет работать с **таблицами Excel** и **презентациями PowerPoint** на задаче: читать прикреплённый файл, для **Excel** — готовить правки и отдавать **новую версию**; для **PowerPoint** и **Word** — анализировать и проверять. Готовый файл сохраняется как **артефакт** (файл результата задачи — см. [Артефакты](../artifacts/overview)): **скачайте** из **Результата** или из каталога **Артефакты**.

Плагин Office — с тарифа **Solo** и выше. Подключите [навык](/docs/cloud/skills) из каталога (вкладка **Сообщество**, сценарии **Excel** / **pptx**). Обзор и тарифы — [Office — обзор](./overview) (раздел в **тестовом режиме**).

![Задача с вложением Excel — сценарий Office](/img/guides/stories/06-excel-office-01-issue.webp)

## Excel

**Что умеет агент:**

- Прочитать структуру книги и найти ошибки
- **Создать или изменить** таблицу по вашим данным — через план правок и [согласование](/docs/concepts/approvals)
- Добавить **формулы**, сводные разрезы и **диаграммы** (в рамках сценария и навыка)
- Выдать **новый `.xlsx`** в блоке **Результат**

### Пример Excel

«Вот данные продаж за год. Сделай **сводную таблицу по менеджерам** и добавь **график динамики по месяцам**». Агент составит план → вы **одобрите** → получите обновлённый файл в задаче. Точный набор формул и диаграмм зависит от [навыка](/docs/cloud/skills).

## PowerPoint и Word

**Что умеет агент сейчас:**

- **Просмотреть** структуру презентации или документа
- **Проверить качество** (оформление, типовые проблемы)
- **Предпросмотр** слайдов или страниц
- **Создать новую презентацию** из данных или текста — через [навыки](/docs/cloud/skills) каталога; результат — [артефакт](../artifacts/overview)

Полный цикл «план → правка слайдов» как у Excel для `.pptx` **пока не поддерживается** — агент не перестраивает готовую презентацию построчно, но может проверить файл и помочь подготовить новый через навык.

### Пример PowerPoint

«Вот **отчёт за квартал** в Word. Сделай **презентацию на 10 слайдов** по ключевым цифрам». Подключите навык для **pptx** — агент подготовит файл; **скачайте** из **Результата**.

### Пример Word

«Проверь **договор поставки**: нет ли односторонних штрафов и неясных сроков». Агент пройдётся по тексту; на **Studio+** замечания можно оформить **аннотациями** — см. [обзор Office](./overview).

## Сводка по форматам

| Формат | Просмотр и анализ | Правки с согласованием |
| --- | --- | --- |
| `.xlsx` | ✅ | ✅ |
| `.docx` | ✅ | — (просмотр и проверка) |
| `.pptx` | ✅ | — (просмотр и проверка; новый файл — через навыки) |

Готовый файл всегда в задаче → [Артефакты](../artifacts/overview).
