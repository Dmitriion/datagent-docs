## Что это даёт вам

ИТ получает первичный обзор проектов и квот Cloud.ru по токену — это **ранний preview**, не полный каталог инфраструктуры. Сейчас доступны **2 инструмента**; для зрелого контроля облака смотрите [Селектел](./selectel) с более широким покрытием.

<h2 id="how-to-connect">Как подключить</h2>

1. Откройте [app.datagent.ru](https://app.datagent.ru) → **Настройки** → **Интеграции** → **Cloud.ru**.
2. Укажите service token (хранится в секретах компании).
3. В карточке агента → **Подключения** включите доступ и задайте первый вопрос.

Коннекторы доступны на тарифах **Studio, Business и Enterprise** — см. [тарифы](/docs/cloud/pricing). Для широкого облачного инвентаря сейчас надёжнее [Селектел](./selectel).

## Ключевые факты

- **2 инструмента** на текущем этапе — проекты, квоты и IAM-сводка
- Статус **«Развивается»** — ранний preview, не production-ready
- Режим **только чтение** — без создания и удаления ресурсов
- Доступ выдаёт администратор: только выбранные агенты
- Версия коннектора **0.1.0**
