## Что это даёт вам

Datagent подключает Ozon Seller к ИИ-агенту: утренний статус FBS, ликвидность остатков и сверка финансов — через вопросы агенту, а не через ручной обход разделов личного кабинета.

Селлеру и операционной команде проще держать отправления под контролем: невыполненные FBS, возвраты, оборачиваемость и транзакции собираются в задаче Datagent с журналом шагов.

Агент не меняет цены, остатки и не отвечает в чатах — только читает данные, к которым вы дали доступ.

## Какие данные агент анализирует

| Область | Что видно агенту |
| --- | --- |
| Каталог | Товары, атрибуты, цены, остатки, рейтинг |
| Заказы | Отправления FBO и FBS, причины отмен, акты |
| Поставки | Заказы поставок, слоты, склады, методы доставки |
| Аналитика | Продажи, ликвидность, оборачиваемость по складам |
| Финансы | Транзакции, реализация, компенсации, баланс |
| Коммуникации | Отзывы, вопросы, чаты (чтение) |

<h2 id="how-to-connect">Как подключить</h2>

1. Откройте [app.datagent.ru](https://app.datagent.ru) → **Настройки** → **Интеграции** → **Ozon Seller**.
2. Укажите Client-Id и Api-Key (хранятся в секретах компании). При необходимости ограничьте склады.
3. В карточке агента → **Подключения** включите Ozon и проверьте вопросом про товары или FBS.

Общий порядок — в [обзоре интеграций](./overview). Коннектор доступен на тарифах **Studio и выше** — см. [тарифы](/docs/cloud/pricing).

## Ключевые факты

- Datagent поддерживает **105 инструментов** для работы с Ozon Seller.
- Коннектор работает в режиме **только чтение**: агент анализирует данные, но не меняет их.
- Доступ получают только агенты, которым его выдал администратор компании.
- Подключение использует официальный Seller API Ozon.
- Версия коннектора **1.6.0** (июль 2026).
