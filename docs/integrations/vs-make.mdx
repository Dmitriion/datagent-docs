# Datagent против Make: что выбрать для автоматизации российских сервисов

Datagent — не российский Zapier/Make и не клон n8n; часто workflow остаётся, Datagent закрывает слой агентов и ответственности. Для digital-команд в РФ ближе сравнение с конструктором сценариев: [Datagent vs n8n](/docs/integrations/vs-n8n). Карта для ИТ: [управление ИИ-агентами](/docs/concepts/upravlenie-ii-agentami).

## Главное отличие одной строкой

Make силён в визуальных ветках сценария. Datagent нужен, когда появляется агент: кому открыты данные, что ждёт «да» человека и где смотреть журнал шагов.

## Сравнение по ключевым критериям

| Критерий | Datagent | Make |
| --- | --- | --- |
| Очередь согласований до рискованного шага | ✅ в продукте: шаг ждёт «да» или отказ | ⚠️ обычно нет из коробки — своя сборка сценария |
| Журнал шагов в задаче | ✅ журнал по задаче агента | ⚠️ история выполнения сценария, не журнал агента компании |
| Права агента на данные компании | ✅ администратор открывает сервисы выбранным агентам | ⚠️ доступ модуля к подключению, не права отдельного агента |
| МойСклад | ✅ **211** инструментов (чтение) | ⚠️ уточните — часто через HTTP |
| Wildberries | ✅ **165** инструментов | ⚠️ уточните / HTTP |
| Ozon | ✅ **105** инструментов | ⚠️ уточните / HTTP |
| Авито | ✅ **104** инструмента | ⚠️ уточните / HTTP |
| Яндекс 360 | ✅ **36** инструментов | ⚠️ уточните |
| ИИ-агент (думает сам) | ✅ задача + инструменты сервисов | ⚠️ сценарии; AI-модули — отдельная модель |
| Работа в России | ✅ продукт под РФ-сервисы | ⚠️ ограничения оплаты/доступа возможны |
| Бесплатный план | ✅ Free / Solo с лимитами | ⚠️ лимиты операций на free |
| Глубина маркетплейсов | ✅ десятки–сотни read-инструментов | ⚠️ зависит от кастомной сборки |

Make силён в сложных ветвлениях и визуальных сценариях. Для МойСклад / WB / Ozon / Авито готового «глубокого» модуля в публичном каталоге обычно нет — типичный путь: HTTP и ручная карта полей.

## Когда выбрать Datagent

- Нужны границы для агента: **доступ** к данным компании, **«да»** перед рискованным шагом и **журнал** задачи
- Работаете с **МойСклад и маркетплейсами** и хотите готовое чтение без сборки каждого метода API — это второе, после границ
- Администратор должен явно открывать сервисы выбранным агентам; готовые коннекторы остаются в режиме только чтения
- Команда в РФ не хочет сопровождать самодельную очередь «да» внутри визуального сценария

## Когда Make подойдёт лучше

- Нужен **визуальный сценарий** с десятками шагов, фильтрами и ветками без «рассуждающего» агента
- Основной стек — западные SaaS, уже описанные модулями Make
- Есть интегратор, который готов поддерживать HTTP-сценарии к российским API
