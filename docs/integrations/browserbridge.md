# BrowserBridge

:::info Studio и выше
**BrowserBridge** доступен начиная с тарифа **Studio**. На **Free** и **Solo** управление браузером недоступно. [Тарифы →](../cloud/pricing)
:::

**BrowserBridge** позволяет агенту работать в браузере как человек: открывать сайты, заполнять формы, нажимать кнопки, скачивать файлы. Страницы открываются в **вашем** Chrome или Edge на рабочем ПК — не в облачном браузере.

**Первый шаг:** [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **BrowserBridge** → мастер **«Облако + ПК»**.

## Когда это нужно

- Выгружать отчёты из систем **без готового API**
- Заполнять формы на сторонних сайтах
- Мониторить изменения на страницах
- Автоматизировать работу в любом веб-интерфейсе, где нет отдельной связки

## Пример

Агент каждый день заходит в личный кабинет поставщика, скачивает прайс-лист и обновляет цены в вашей таблице. Без API, без разработчика — вы подтверждаете рискованные шаги в [согласованиях](../concepts/approvals).

## Как подключить

1. Убедитесь, что у компании тариф **Studio** или выше.
2. **Менеджер плагинов** → установите и включите **BrowserBridge**.
3. **Настройки компании → BrowserBridge** → мастер **«Облако + ПК»** на рабочем ПК (Node.js 20+, расширение для браузера).
4. Дождитесь статуса **«В сети»** — задайте **политику адресов**, разрешите действия в браузере у агента.

Подробнее: [Подключение BrowserBridge](../browser/setup) · [Обзор](../browser/overview).

## Что умеет агент

| Задача | Пример |
| --- | --- |
| Открыть страницу | Статус заказа на сайте перевозчика |
| Скриншот или текст | Отчёт в задаче с доказательством |
| Заполнить форму | Рутина на портале под вашим контролем |
| CRM в браузере | Раздел Битрикс24 без отдельной связки с чатами |

**BrowserBridge не нужен**, если хватает [Битрикс24](./bitrix24), готового API или файлов на задаче.

## Подтверждения и безопасность

- Отправка формы и опасные клики — [подтверждения](../concepts/approvals).
- **Политика адресов** ограничивает, куда агент может переходить.
- Не включайте браузер всем агентам без необходимости.

## Частые вопросы

**Облачный браузер?**  
**Нет** — ваш Chrome или Edge на вашем ПК.

**Нужен программист?**  
Нет для ежедневной работы; первое подключение — по мастеру.

**Работает на Free?**  
**Нет** — **Studio** и выше.
