# Управление браузером (BrowserBridge)

Пошаговая инструкция — [Подключение](../browser/setup). Краткий обзор для руководителя — [Браузер: обзор](../browser/overview).

:::info[Studio — сайты без готового API]
**Studio** — агент открывает сайты на вашем ПК, заполняет формы и скачивает отчёты там, где нет отдельной связки с CRM. [Тарифы →](../cloud/pricing)
:::

**BrowserBridge** позволяет ИИ-исполнителю работать в браузере как человек: открывать страницы, нажимать кнопки, заполнять формы, снимать текст и скриншоты. Страницы открываются в **вашем** Chrome на рабочем компьютере — не в облачном браузере. Пароли и сессии остаются у вас: агент использует уже открытую авторизацию на сайтах.

**Первый шаг:** установите расширение [Datagent BrowserBridge в Chrome Web Store](https://chromewebstore.google.com/detail/datagent-browserbridge/onlphfpiiegbgjmfihbimgnmpbleaelh?hl=ru), затем в [app.datagent.ru](https://app.datagent.ru) выпустите токен в разделе **BrowserBridge** и вставьте его в расширение.

## Когда это нужно

- Выгружать отчёты из систем **без готового API**
- Заполнять формы на сторонних сайтах и порталах
- Проверять витрину, статус заказа или кабинет поставщика
- Вести работу в CRM или внутреннем веб-интерфейсе прямо в браузере
- Держать задачу Datagent **рядом с сайтом** в боковой панели Chrome

## Пример

Агент каждый день заходит в личный кабинет поставщика, скачивает прайс-лист и обновляет цены в вашей таблице. Без API и без передачи паролей на сервер Datagent — вы задаёте список разрешённых сайтов и следите за ходом в журнале задачи.

## Как подключить

1. Убедитесь, что у компании тариф **Studio** или выше.
2. Установите [Datagent BrowserBridge из Chrome Web Store](https://chromewebstore.google.com/detail/datagent-browserbridge/onlphfpiiegbgjmfihbimgnmpbleaelh?hl=ru).
3. В [app.datagent.ru](https://app.datagent.ru) откройте **Настройки компании → BrowserBridge** (или **Менеджер плагинов → BrowserBridge**).
4. Выпустите **персональный токен**, вставьте его в popup расширения и нажмите **Сохранить**.
5. В popup разрешите нужные сайты («Разрешить все сайты» или конкретный домен).
6. Дождитесь статуса **«В сети»**, задайте **политику адресов** в панели и включите работу с браузером у нужного агента.

Подробнее: [Подключение BrowserBridge](../browser/setup).

## Что умеет агент

| Задача | Пример |
| --- | --- |
| Открыть страницу | Статус заказа на сайте перевозчика |
| Скриншот или текст | Доказательство в задаче |
| Клики, ввод, прокрутка | Заполнение формы на портале |
| Боковая панель | Задача Datagent справа, сайт слева |
| Пауза автоматизации | Остановить действия с панели на странице |

**BrowserBridge не нужен**, если хватает [Битрикс24](./bitrix24), готового API или файлов на задаче.

## Безопасность и контроль

- Доступ к сторонним сайтам — **только после вашего разрешения** в расширении.
- **Политика адресов** в панели ограничивает, куда агент может переходить.
- Автоматизация идёт в вашем браузере; управление — через защищённое соединение с app.datagent.ru.
- Не включайте браузер всем агентам без необходимости.
- Перед рискованными сценариями смотрите [согласования](../concepts/approvals) и журнал задачи — единый «стоп перед каждой формой» зависит от настроек компании и сценария, поэтому не обещаем его для всех действий подряд.

## Частые вопросы

**Это облачный браузер?**  
**Нет** — ваш Chrome (или другой Chromium-браузер) на вашем ПК.

**Нужен программист?**  
Нет для ежедневной работы: расширение из магазина и токен из панели.

**Нужен Node.js на ПК?**  
Для обычного облачного пути через Chrome Web Store — **нет**. Технические режимы для администраторов — в [инструкции подключения](../browser/setup).

**Работает на Free?**  
**Нет** — **Studio** и выше.

**Не получается войти на сайт (капча, СМС, банк)?**  
См. ограничения в [обзоре браузера](../browser/overview) — такие порталы обычно не подходят.
