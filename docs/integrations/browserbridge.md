# Подключите BrowserBridge к агенту

Задаче нужен **реальный сайт** — форма, личный кабинет, портал без API. BrowserBridge даёт агенту **ваш браузер** на рабочем компьютере. Подключение — в [app.datagent.ru](https://app.datagent.ru).

> **Доступно на тарифе Studio и выше.**  
> На **Free** и **Solo** управление браузером недоступно. [Тарифы →](../cloud/pricing)

## Как подключить

1. Убедитесь, что у компании тариф **Studio** или **Business**.
2. **Менеджер плагинов** → установите и включите **BrowserBridge**.
3. **Настройки компании → BrowserBridge** → мастер **«Облако + ПК»**.
4. На ПК — скрипты **setup** и **pair** (Node.js 20+), расширение в браузере.
5. Статус **«В сети»** → политика URL → инструменты `browser_*` у агента.

Пошагово: [Подключение BrowserBridge](../browser/setup) · [Обзор](../browser/overview).

## Что умеет браузер-агент

| Задача | Пример |
| --- | --- |
| Открыть страницу | Статус заказа на сайте перевозчика |
| Скриншот или текст | Отчёт в задаче с доказательством |
| Заполнить форму | Рутина на портале под вашим контролем |
| CRM в браузере | Раздел Битрикс24 без отдельного API |

**BrowserBridge не нужен**, если хватает [Битрикс24](./bitrix24), API или файлов на задаче.

## Подтверждения и безопасность

- Отправка формы и опасные клики — [подтверждения](../concepts/approvals).
- **Политика URL** ограничивает, куда агент может переходить.
- Не включайте browser_* всем агентам без необходимости.

## Частые вопросы

**Облачный браузер?**  
**Нет** — ваш Chromium на вашем ПК.

**Нужен программист?**  
Нет для ежедневной работы; первое подключение — по мастеру.

**Работает на Free?**  
**Нет** — **Studio** и выше.
