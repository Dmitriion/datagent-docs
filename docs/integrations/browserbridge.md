# Подключите BrowserBridge к агенту

Агент **открывает страницы на вашем ПК**, **снимает скриншоты**, **заполняет формы** и **работает в CRM через браузер** — когда готовой связки с API нет.

Подходит, если сотрудники каждый день вручную заходят на порталы, копируют данные в таблицы или задачи — агент повторяет маршрут, вы остаётесь в панели Datagent.

**Начните так:** [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **BrowserBridge** → мастер **«Облако + ПК»**. Тариф **Studio** или **Business**.

> **Доступно на тарифе Studio и выше.**  
> На **Free** и **Solo** управление браузером недоступно. [Тарифы →](../cloud/pricing)

## Как подключить

1. Убедитесь, что у компании тариф **Studio** или **Business**.
2. **Менеджер плагинов** → установите и включите **BrowserBridge**.
3. **Настройки компании → BrowserBridge** → мастер **«Облако + ПК»**.
4. На ПК — скрипты настройки и сопряжения (Node.js 20+), расширение для браузера.
5. Статус **«В сети»** → политика адресов → действия в браузере у агента.

Пошагово: [Подключение BrowserBridge](../browser/setup) · [Обзор](../browser/overview).

## Что умеет агент

| Задача | Пример |
| --- | --- |
| Открыть страницу | Статус заказа на сайте перевозчика |
| Скриншот или текст | Отчёт в задаче с доказательством |
| Заполнить форму | Рутина на портале под вашим контролем |
| CRM в браузере | Раздел Битрикс24 без отдельной связки |

**BrowserBridge не нужен**, если хватает [Битрикс24](./bitrix24), готового API или файлов на задаче.

## Подтверждения и безопасность

- Отправка формы и опасные клики — [подтверждения](../concepts/approvals).
- **Политика адресов** ограничивает, куда агент может переходить.
- Не включайте браузер всем агентам без необходимости.

## Частые вопросы

**Облачный браузер?**  
**Нет** — ваш Chrome или Edge на вашем ПК.

**Нужен программист?**  
Нет для ежедневной работы; первое подключение — по мастеру.

**Работает на Free?**  
**Нет** — **Studio** и выше.
