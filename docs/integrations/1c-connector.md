# 1С

:::info[Business — данные из учёта без ручной выгрузки]
**Business** — команда забирает остатки, продажи и регистры из **1С** через коннектор; оператор получает готовые сводки в задачах Datagent. [Тарифы →](../cloud/pricing)
:::

Команда подключает Datagent к вашей **1С** и получает данные учёта без ежедневных выгрузок в Excel: остатки, обороты, справочники, ответы на вопросы по базе. Финдиректор видит актуальную цифру в отчёте — без пересылки файлов в чат.

**Первый шаг:** [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **1С Коннектор** → **Настройки компании → 1С** → адрес опубликованной базы → **Проверить соединение**.

![Страница настройки 1С-коннектора](/img/guides/1c/connector-page.webp)

:::tip[Честно о возможностях]
Из карточки задачи агент **не проводит документы** в 1С одной кнопкой — коннектор даёт **доступ к данным** для команды и Cursor-агентов, не замену бухгалтера в интерфейсе 1С.
:::

## Что умеет команда с коннектором 1С

- Читать данные из **справочников и регистров**
- Получать **остатки, обороты**, номенклатуру и контрагентов
- Отвечать на вопросы по данным 1С в отчётах и задачах
- Формировать **отчёты и выборки** на основе опубликованной базы
- Дать **Cursor-агенту** в Datagent доступ к разрешённым инструментам 1С во время задачи (после назначения на вкладке **Подключения**)

Создание и проведение документов — через доработку с вашим разработчиком, не «из коробки» в задаче.

## Как подключить

:::warning[Нужна помощь администратора 1С]
Первое подключение делает **администратор или разработчик 1С** (публикация базы, расширение). Со стороны Datagent — несколько шагов в панели после того, как вам передали адрес базы.
:::

1. Администратор 1С **публикует базу** (расширение MCP_Server, HTTP-сервис) и передаёт **адрес публикации**.
2. В Datagent: **Менеджер плагинов** → **1С Коннектор** → **Настройки компании → 1С** → укажите адрес → **Проверить соединение** (нужны права управления интеграциями).
3. В карточке агента с адаптером **Cursor** откройте **Подключения** и включите нужное подключение 1С (имя / id должно совпасть с `cursorServerName` в коннекторе). Operator может назначить без прав на изменение credentials.
4. При необходимости скопируйте настройки для Cursor IDE разработчика.

Подробнее для 1С-администратора — [руководство по подключению 1С](../guides/08-1c-bridge).  
Связанная тема — [внешние инструменты (MCP)](./mcp).

## Как работает доступ агента к 1С

| Кто | Что делает |
| --- | --- |
| Администратор 1С | Публикует базу и расширение |
| Оператор / админ Datagent | Включает коннектор, проверяет связь |
| Cursor-агент в задаче | Вызывает **разрешённые** инструменты 1С во время запуска |
| Оператор | Получает сводки, таблицы и ответы в задаче |

**Важно:**

- Работает для агентов с адаптером **Cursor**, не для всех моделей подряд.
- Агент видит только те подключения 1С, которые ему **явно разрешили**.
- Зелёный статус коннектора в настройках ещё не гарантирует успех в старой сессии агента — для проверки лучше короткая новая задача.

## Частые вопросы

**Нужен ли Datagent Cloud?**  
Да, на [app.datagent.ru](https://app.datagent.ru); корпоративное развёртывание — [свой сервер](../cloud/on-premise). Тариф **Business** или выше.

**Агент в задаче сам проведёт документ?**  
**Нет** без отдельной интеграции. Коннектор — **данные и контролируемый доступ**, не замена регламентов учёта.

**Безопасно ли?**  
Ограничьте права пользователя 1С, закройте доступ к прокси снаружи, не храните пароли в тексте задач.

**Связка с Битрикс24?**  
Отдельный плагин: [Битрикс24](./bitrix24). 1С Коннектор — про **учёт и данные**, не про чат с клиентом.

### HTTP API плагина (board auth)

| Method | Path | Назначение |
| --- | --- | --- |
| GET | `/status` | Статус proxy, upstream |
| POST | `/test-connection` | Проверка учётных данных |
| GET | `/cursor-config` | Фрагмент `mcp.json` |
| GET | `/extension-file` | Скачать `.cfe` |

### Диагностика

| Симптом | Проверить |
| --- | --- |
| `lastListToolsError` | JSON-RPC, версия расширения, права 1С |
| Proxy не стартует | Порт 8010, «Перезапустить прокси», логи worker |
| Агент не видит 1С | Agent → **Подключения**: grant включён; id = `cursorServerName` в коннекторе; адаптер Cursor |
