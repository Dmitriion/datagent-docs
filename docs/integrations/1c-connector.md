# 1С

:::info Business и выше
Коннектор **1С** доступен начиная с тарифа **Business** (12 900 ₽/мес). На Free, Solo и Studio плагин недоступен. [Тарифы →](../cloud/pricing)
:::

Агент и команда подключаются к вашей **1С** и работают с данными напрямую: читают справочники, получают остатки и обороты, отвечают на вопросы по учёту. Финдиректор видит актуальную цифру без ежедневных выгрузок в Excel.

**Первый шаг:** [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **1С Коннектор** → **Настройки компании → 1С** → адрес опубликованной базы → **Проверить соединение**.

:::tip Честно о возможностях
Из карточки задачи агент **не проводит документы** в 1С одной кнопкой — коннектор даёт **доступ к данным** и сценарии для команды и разработчиков, не замену бухгалтера в интерфейсе 1С.
:::

## Что умеет команда с коннектором 1С

- Читать данные из **справочников и регистров**
- Получать **остатки, обороты**, номенклатуру и контрагентов
- Отвечать на вопросы по данным 1С в отчётах и задачах
- Формировать **отчёты и выборки** на основе опубликованной базы

Создание и проведение документов — через доработку сценариев и MCP (см. ниже), не «из коробки» в задаче.

## Как подключить

1. Администратор 1С **публикует базу** (расширение MCP_Server, HTTP-сервис) и передаёт **адрес публикации**.
2. В Datagent: **Менеджер плагинов** → **1С Коннектор** → **Настройки компании → 1С** → укажите адрес → **Проверить соединение**.
3. При успехе — **Скопировать настройки для Cursor** (если подключаете разработчиков).

Подробнее для 1С-администратора — [учебник: мост с 1С](../guides/08-1c-bridge).

## Для разработчиков

Коннектор поддерживает **MCP-интерфейс** — это позволяет встроить запросы к 1С в **Cursor** и существующие сценарии автоматизации.

Агент в **задаче Datagent** к 1С **напрямую не обращается** без отдельной доработки; типичный путь — данные через коннектор + навыки/скрипты команды.

Подробнее → [Плагины (API)](../api-reference/plugins)

## Частые вопросы

**Нужен ли Datagent Cloud?**  
Да, на [app.datagent.ru](https://app.datagent.ru); корпоративное развёртывание — [Enterprise](../cloud/on-premise). Тариф **Business** или выше.

**Агент в задаче сам проведёт документ?**  
**Нет** без отдельной интеграции. Коннектор — **данные и разработка**.

**Безопасно ли?**  
Ограничьте права пользователя 1С, закройте доступ к прокси снаружи, не храните пароли в тексте задач.

**Связка с Битрикс24?**  
Отдельный плагин: [Битрикс24](./bitrix24). 1С Коннектор — про **учёт и данные**, не про чат с клиентом.

Локальная разработка плагина:

```bash
pnpm --filter @datagent/plugin-1c-connector build
pnpm datagent plugin install packages/plugins/plugin-1c-connector
```

| Поле | Значение |
| --- | --- |
| Plugin id | `datagent.1c-connector` |
| UI route | `1c-connector` |
| Default proxy port | `8010` |
| Agent tools в manifest | **Нет** |

### HTTP API плагина (board auth)

| Method | Path | Назначение |
| --- | --- | --- |
| GET | `/status` | Статус proxy, upstream |
| POST | `/test-connection` | Проверка учётных данных |
| GET | `/cursor-config` | Фрагмент `mcp.json` |
| GET | `/extension-file` | Скачать `.cfe` |

### Диагностика

| Симптом | Проверить |
| --- | --- |
| `lastListToolsError` | JSON-RPC, версия расширения, права 1С |
| Proxy не стартует | Порт 8010, `restart-proxy`, логи worker |
| WSL / Docker | `DATAGENT_1C_CONNECTOR_PUBLIC_HOST` |

См. [Обзор API](../api-reference/overview.md).
