# Как подключить 1С к Datagent — данные учёта для команды

Через коннектор команда **запрашивает остатки, обороты и справочники из 1С** без ежедневных выгрузок в Excel и пересылки файлов в чат. Финдиректор видит актуальную цифру в отчёте, бухгалтерия не копирует одно и то же вручную — данные берутся из опубликованной базы.

Если закрытие месяца тормозит из‑за «попросите 1С выгрузить ещё раз» — коннектор даёт единую точку доступа: настроил администратор один раз, дальше разработчик или аналитик запрашивает нужные поля по запросу.

**Начните так:** на тарифе **Business** откройте [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **1С Коннектор** → **Настройки компании → 1С** → вставьте **адрес опубликованной базы** и нажмите **Проверить соединение**.

> **Коннектор 1С доступен на тарифе Business и выше.**  
> На Free, Solo и Studio плагин недоступен. [Тарифы →](../cloud/pricing)

## Что можно получить из 1С

| Задача | Что это даёт |
| --- | --- |
| **Остатки и обороты** | Сверка перед отчётом руководству без ручной выгрузки |
| **Справочники** | Номенклатура, контрагенты — для сверки и подготовки документов |
| **Метаданные и отчёты** | Разработчик или интегратор строит автоматизацию на актуальной структуре базы |
| **Проверка после обновления** | Убедиться, что публикация базы жива после релиза 1С |

**Честно:** из карточки задачи Datagent «провести накладную» кнопкой нельзя — коннектор для **доступа к данным и разработки**, не замена бухгалтера в интерфейсе 1С.

## Способы подключения 1С

### Через облачный коннектор [Business+]

Плагин в [app.datagent.ru](https://app.datagent.ru) поднимает связь между **опубликованной базой 1С** и вашей компанией в Datagent. На сервер Datagent ничего не ставите — нужны публикация HTTP в 1С и адрес в панели.

Подходит финслужбе и IT: один раз настроили — команда запрашивает данные без локальных скриптов у каждого сотрудника.

### Через редактор кода [для разработчиков]

После настройки плагина копируете фрагмент настроек в **Cursor** (или другую среду с MCP) — 1С-разработчик вызывает запросы к базе прямо из редактора. Агент в **задаче Datagent** к 1С **напрямую не обращается** без отдельной доработки.

## Подключение по шагам

### Шаг 1. Публикация в 1С

Попросите администратора 1С:

1. Установить расширение **MCP_Server** (файл `.cfe` — на странице плагина в Datagent).
2. Включить HTTP-сервис в расширении.
3. **Опубликовать** базу на веб-сервере (IIS и т.п.).
4. Передать вам **адрес публикации**, например `https://host/app`.

### Шаг 2. Плагин в Datagent

1. [app.datagent.ru](https://app.datagent.ru) → **Менеджер плагинов** → **1С Коннектор**.
2. **Настройки компании → 1С**.
3. Укажите **адрес публикации 1С**.
4. **Проверить соединение** — логин и пароль пользователя 1С с нужными правами.
5. При успехе — **Скопировать настройки для Cursor** (для команды разработки).

### Шаг 3. Проверка для разработки

Если подключаете Cursor — вставьте выданный фрагмент в настройки MCP, перезапустите среду, выполните тестовый запрос к справочнику.

## Частые вопросы

**Нужен ли Datagent Cloud?**  
Да, на [app.datagent.ru](https://app.datagent.ru); корпоративное развёртывание — по [Enterprise](../cloud/on-premise). Тариф **Business** или выше.

**Агент в задаче сам проведёт документ?**  
**Нет** без отдельной интеграции. Коннектор — **данные и разработка**, не кнопка в задаче.

**Безопасно ли?**  
Ограничьте права пользователя 1С, закройте доступ к прокси снаружи, не храните пароли в тексте задач.

**Связка с Битрикс24?**  
Отдельный плагин: [Битрикс24](./bitrix24). 1С Коннектор — про **учёт и данные**, не про чат с клиентом.

pnpm --filter @datagent/plugin-1c-connector build

| --- | --- |
| Plugin id | `datagent.1c-connector` |
| UI route | `1c-connector` |
| Default proxy port | `8010` |
| Agent tools в manifest | **Нет** |

### HTTP API плагина (board auth)

| Method | Path | Назначение |
| --- | --- | --- |
| GET | `/status` | Статус proxy, upstream |
| POST | `/test-connection` | Проверка учётных данных |
| GET | `/cursor-config` | Фрагмент `mcp.json` |
| GET | `/extension-file` | Скачать `.cfe` |

### Диагностика

| Симптом | Проверить |
| --- | --- |
| `lastListToolsError` | JSON-RPC, версия расширения, права 1С |
| Proxy не стартует | Порт 8010, `restart-proxy`, логи worker |
| WSL / Docker | `DATAGENT_1C_CONNECTOR_PUBLIC_HOST` |
