## Что это даёт вам

Datagent подключает Seller API Wildberries к ИИ-агенту: вместо десяти вкладок личного кабинета вы задаёте вопрос про заказы, остатки, рекламу или финансы и получаете сводку по актуальным данным.

Селлеру и операционной команде проще держать руку на пульсе: просадки в воронке, риск out-of-stock, расход рекламного бюджета и новые отзывы — в одной задаче Datagent с понятным журналом шагов.

Агент не меняет цены, остатки и не отвечает покупателям — только анализирует то, что разрешил администратор.

## Какие данные агент анализирует

| Область | Что видно агенту |
| --- | --- |
| Контент | Карточки, категории, бренды, ошибки и лимиты |
| Заказы | FBS, DBS, DBW, самовывоз — списки и статусы |
| Поставки | FBW-поставки, склады, транзиты |
| Аналитика | Воронка, поисковые и стоковые отчёты |
| Реклама | Баланс, бюджеты, кампании, статистика |
| Финансы и отзывы | Баланс, отчёты о продажах, отзывы и вопросы (чтение) |

<h2 id="how-to-connect">Как подключить</h2>

1. Откройте [app.datagent.ru](https://app.datagent.ru) → **Настройки** → **Интеграции** → **Wildberries**.
2. Укажите API-токен продавца (хранится в секретах компании). При необходимости ограничьте склады.
3. В карточке агента → **Подключения** включите Wildberries и проверьте вопросом про заказы или карточки.

Общий порядок — в [обзоре интеграций](./overview). Коннектор доступен на тарифах **Studio и выше** — см. [тарифы](/docs/cloud/pricing).

## Ключевые факты

- Datagent поддерживает **165 инструментов** для работы с Wildberries.
- Коннектор работает в режиме **только чтение**: агент анализирует данные, но не меняет их.
- Доступ получают только агенты, которым его выдал администратор компании.
- Подключение использует официальный Seller API Wildberries.
- Версия коннектора **1.10.0** (июль 2026).
