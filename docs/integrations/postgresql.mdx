## Что это даёт вам

Руководитель и аналитик получают сводки по подготовленным представлениям, формулируя вопросы как в переписке с коллегой. Агент видит **только разрешённые представления**, не выполняет произвольный SQL и не меняет данные.

<h2 id="how-to-connect">Как подключить</h2>

1. Откройте [app.datagent.ru](https://app.datagent.ru) → **Настройки** → **Интеграции** → **PostgreSQL**.
2. Укажите параметры подключения и **список разрешённых представлений**.
3. В карточке агента → **Подключения** включите доступ и задайте первый вопрос.

Коннекторы доступны на тарифах **Studio, Business и Enterprise** — см. [тарифы](/docs/cloud/pricing). Общий порядок — в [обзоре интеграций](./overview).

## Ключевые факты

- **13 инструментов** для чтения разрешённых представлений PostgreSQL
- Режим **только чтение** — без изменения данных и без произвольного SQL
- Агент видит **только представления из белого списка** администратора
- Требуется sidecar на хосте приложения (`127.0.0.1:4174`) — плагин сам БД не поднимает
- Доступ выдаёт администратор: только выбранные агенты
- Версия коннектора **0.4.0**
