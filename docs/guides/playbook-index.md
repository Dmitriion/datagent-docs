Нужен маршрут, а не перечитывать восемь глав? Ниже — **ситуация → что сделать → куда открыть**. Подробная настройка и API — в колонке «Глубже». Откройте нужную строку и переходите по ссылке.

## Ежедневная работа оператора

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Первый вход, страшно от интерфейса | Пройти меню: Задачи, Агенты, Согласования | [1. Первый день](./01-first-day) |
| Нужен ответ по одной теме | Задача → Запуск → журнал | [3. Одна задача](./03-one-task) |
| Висит «ждёт решения» / бот молчит | **Согласования**, прочитать карточку | [4. Согласования](./04-trust-and-approval) |
| Непонятно, что агент умеет | Карточка агента: инструменты и плагины | [2. Команда](./02-your-team) |

## Руководитель

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Картина команды за несколько секунд | Раздел **«Офис»** (если включён) | [5. Офис](./05-office-field) |
| Кто ждёт согласования | Подсветка на поле, вкладка **Агенты** | [5. Офис](./05-office-field) |
| Портфель проектов на поле | Вкладка **Проекты** | [Обзор «Офис»](../office/overview) |

## Каналы и файлы

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Клиент пишет в Битрикс24 | Найти задачу → запуск → при необходимости уточнить | [6. Каналы](./06-channels), [Битрикс24](../integrations/bitrix24) |
| Пришло согласование в Телеграм | Кнопки ведут в то же решение, что в панели | [Телеграм](../integrations/telegram) |
| Правка Excel | Вложение → план → согласование → применение | [7. Документы](./07-documents) |
| Проверить презентацию | Просмотр и проверка (без полного цикла как у Excel) | [7. Документы](./07-documents) |
| 1С для разработки, не для оператора | Страница коннектора, проверка связи, настройка IDE | [8. 1С](./08-1c-bridge) |

## Когда звать инженера

| Симптом | Вероятная причина | Док |
| --- | --- | --- |
| Запуск завершился с ошибкой | Адаптер, секреты, таймаут инструмента | [Первый агент](../cloud/first-agent) |
| Инструмент не виден агенту | Плагин не установлен или не выдан агенту | [Создание плагина](../tutorials/build-plugin) |
| Применение правок Excel «висит» | Очередь согласований не разобрана | [4. Согласования](./04-trust-and-approval) |
| 1С недоступна | Публикация, авторизация, веб-сервер | [1С Коннектор](../integrations/1c-connector) |

## Чего нет в продукте (не обещайте)

- Публичный API «создать запуск в обход агента»
- Панель на отдельном порту `:3200`
- Штатные кнопки «выгрузить лиды Битрикс24» или «отправить в Телеграм» из коробки
- Проведение документов 1С агентом прямо из карточки задачи
