Учебник по работе с агентами

За один вечер вы поймёте, зачем Datagent в компании: не «ещё один чат», а control plane — кто работает, что запущено и где ждёт ваше решение. Board и API на одном адресе (по умолчанию http://localhost:3100); каждый запуск агента — heartbeat run с журналом. Self-hosted: данные остаются у вас.

Ниже — учебник из историй, не справочник API. Читайте, как сценарии коллег, которые завтра откроют Board как рабочий инструмент.

Обложка: control plane на :3100 — задачи, агенты, согласования.

:::tip Первый раз в продукте? Быстрый старт и первый агент — 15–20 минут. Затем первый день в Board. :::

Поиск и вход​

Быстрый переход к задаче или агенту.

Если компаний несколько — picker перед входом в префикс.

Пример empty state: вкладка без агентов — нормальная ситуация для новой компании.

Путь читателя​

Что вы получите по времени​

ВремяРезультат
~30 минОриентируетесь в Board: агент, задача (issue), wakeup; знаете, где очередь одобрений
~60 минПроходите одну задачу от формулировки до ответа; читаете журнал run
~90 минСвязываете Офис, Bitrix24, Телеграм и файлы на задаче — без дубля техдоков
