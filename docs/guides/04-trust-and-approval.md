**Мария** боится, что агент «сам отправит» письмо или испортит таблицу. **Алексей** боится обратного: если всё вручную — зачем агент. Datagent держит середину: **работает до порога риска**, дальше — вы.

## Было и стало

| Было | Стало |
| --- | --- |
| Либо полный запрет tools | Tools + **одобрение** на опасное |
| «Не знаю, ждёт ли бот» | Inbox **Одобрения** + уведомления |
| Решения в личке | Решение в Board, run продолжается |

## Что происходит в пятницу с Excel

**Шаг 1.** Агент «Оформитель таблиц» в задаче с `.xlsx` вызывает `plan_workbook_changes`. Office Plugin помечает риск — нужно [одобрение](../office/excel-pptx).

**Шаг 2.** В **Одобрения** появляется запрос: что изменится, какой plan id.

**Шаг 3.** Параллельно в [Телеграм](../integrations/telegram) — push с кнопками, если админ настроил `approvalsChatId`.

**Шаг 4.** Вы открываете задачу, смотрите вложение и план. Одобряете.

**Шаг 5.** Агент (следующий wakeup или сценарий плагина) вызывает `apply_workbook_changes`. Новый файл — вложение на задаче.

**Шаг 6.** При отклонении run не доделывает спорный шаг; уточняете задачу и запускаете снова.

```mermaid
sequenceDiagram
  participant A as Агент
  participant P as Office Plugin
  participant S as server
  participant M as Мария
  A->>P: plan_workbook_changes
  P->>S: запрос одобрения
  S-->>M: Board и Телеграм
  M->>S: одобрить
  S->>A: продолжение run
  A->>P: apply_workbook_changes
```

Так же работают одобрения для **BrowserBridge** (`browser_action`) и явный **`request_board_approval`** в manifest плагинов.

## Где встроен governance

На совещании Алексей говорит: «Мы не отключили агентов — мы **встроили governance**». Очередь одобрений — метрика зрелости, не бюрократия ради бюрократии.

:::info Пространство «Офис»
При `enableOffice` статус **ждёт одобрения** виден на поле (`pending_approval`) — [глава 5](./05-office-field).
:::

## Что нельзя делать с одобрениями

:::warning
- Жать «да», не читая задачу — вы отвечаете за шаг, не за кнопку.
- Держать запрос неделю — run может ждать; SLA одобрений — ваша дисциплина.
- Считать Телеграм заменой Board — push дублирует, решение живёт в control plane.
:::

## Быстрая победа за 5 минут

:::tip
Откройте **Одобрения**. Пусто — запомните путь. Есть запрос — прочитайте один до конца и примите учебное решение.
:::
