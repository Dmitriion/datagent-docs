# Как получать регулярные отчёты с ИИ-агентом

В Datagent регулярный отчёт — это **повторный запуск агента по расписанию** с тем же поручением: сводка за вчера, контроль просрочек, дайджест по рекламе. Расписание задаёт [регламент](/docs/concepts/routines); данные агент берёт только из **разрешённых** подключений. Автономных «решений без проверки» платформа не обещает.

## Если коротко

- Регламент отвечает на вопрос *когда* запускать агента.
- Поручение и формат результата задаёте вы один раз в задаче или шаблоне.
- Каждый запуск расходует квоту запусков тарифа.
- Результат проверяете в задаче и [журнале](/docs/concepts/heartbeat).

## Когда это подходит

- Нужна утренняя или еженедельная сводка без ручного «Запустить».
- Источник данных уже подключён (CRM, маркетплейс, склад, реклама и т.д.) или отчёт строится по тексту/файлам в задаче.
- Есть оператор, который смотрит результат и правит поручение при смене процесса.

## Как это работает

```text
Данные (подключения) → поручение агенту → регламент (расписание) → запуск → проверка в журнале
```

1. Подключите сервис или подготовьте факты в задаче — см. [интеграции](/docs/integrations/overview).
2. Сформулируйте поручение и формат выхода — см. [первая задача](/docs/guides/03-one-task).
3. Создайте [регламент](/docs/concepts/routines): агент, текст/шаблон, расписание (например, пн–пт 08:30).
4. Включите регламент и откройте результат после первого срабатывания.

## Пример

Поручение: «Каждый будний день в 09:00 подготовь краткую сводку по просроченным сделкам из разрешённой CRM: этап, менеджер, дней просрочки. Без изменений в CRM».

Агент читает данные в режиме **только чтение** (для Russia-коннекторов), пишет ответ в задачу. Руководитель проверяет сводку перед планёркой.

## Что потребуется

- Агент с рабочей моделью и ключами в секретах.
- Понятное поручение и критерии готовности.
- Для данных из сервисов — подключение и права агента (часто **Studio+** для готовых коннекторов).
- Учёт [лимита запусков](/docs/concepts/credits): каждое срабатывание регламента = один запуск.

## Ограничения

- Регламент не заменяет согласования: рискованные шаги по-прежнему могут ждать подтверждения.
- Плотное расписание на **Free** быстро исчерпает 100 запусков в месяц.
- Качество сводки зависит от доступных данных и формулировки поручения — проверяйте результат.
