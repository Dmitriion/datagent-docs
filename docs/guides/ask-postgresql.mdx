# Как задать вопрос к PostgreSQL без SQL

В Datagent агент отвечает на вопросы к **PostgreSQL обычным языком**, используя только **разрешённые представления**. Произвольный SQL и изменение данных недоступны: режим **только чтение**, 13 инструментов коннектора (v0.4.0). Это ускоряет сводки для руководителя и аналитика, но не заменяет проверку бизнес-смысла ответа.

## Если коротко

- Агент видит только представления, которые открыл администратор.
- Вопросы формулируете как коллеге: «сводка за месяц», «сравни периоды».
- База не меняется; произвольные запросы не выполняются.
- Нужны подключение PostgreSQL и доступ агента (как у других коннекторов — см. тарифы Studio+ для готовых Russia-коннекторов в [каталоге](/docs/integrations/overview)).

## Когда это подходит

- Типовые отчёты уже оформлены как представления в БД.
- Нужны текстовые сводки без написания SQL в чате.
- Есть человек, который проверит цифры перед решением.

## Как это работает

1. Администратор подключает PostgreSQL и задаёт allowlist представлений — детали на странице [PostgreSQL](/docs/integrations/postgresql).
2. Агенту выдают доступ на вкладке **Подключения**.
3. Вы создаёте [задачу](/docs/guides/03-one-task) с вопросом на естественном языке.
4. Агент читает разрешённые данные и возвращает сводку в задачу; вы проверяете результат.

## Примеры вопросов

- «Подготовь краткую сводку по разрешённому представлению продаж за месяц».
- «Сравни показатели двух периодов в выбранном представлении».
- «Какие метрики доступны агенту в разрешённых представлениях?»
- «Покажи топ отклонений по доступным полям без изменения данных».
- «Собери список показателей для планёрки только из открытых представлений».

## Что потребуется

- Рабочий агент в [Cloud](/docs/cloud/getting-started) или вашем контуре.
- Настроенный коннектор [PostgreSQL](/docs/integrations/postgresql) и непустой allowlist представлений.
- Понятная формулировка периода и метрик в задаче.

## Ограничения

- Нет произвольного SQL и записи в таблицы.
- Ответ ограничен схемой разрешённых представлений: «нет данных» часто значит «нет в allowlist», а не «в компании ноль».
- Агент не гарантирует юридическую или финансовую интерпретацию — проверяйте цифры.
- Статус коннектора и число инструментов актуальны на странице интеграции; при расхождении ориентируйтесь на неё.
