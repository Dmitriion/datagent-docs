# Найдите действие по ситуации

<GuideMeta audience="Все роли" level="Начальный" />

Нужен маршрут, а не перечитывать все главы? Ниже — **ситуация → что сделать → куда открыть**.

## Ежедневная работа оператора

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Первый вход | Пройти меню: Задачи, Агенты, Согласования | [Первый день](./01-first-day) |
| Нужен ответ по одной теме | Задача → Запуск → журнал | [Первая задача](./03-one-task) |
| Висит «ждёт решения» | Раздел **Согласования** | [Согласования](./04-trust-and-approval) |
| Непонятно, что умеет агент | Карточка агента: инструменты | [Команда агентов](./02-your-team) |
| Повторяющийся поток заявок | **Конвейеры** → доска → очередь проверки | [Конвейеры](../workflows/pipelines) |

## Руководитель

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Картина команды | Раздел **Офис** (если включён) | [Офис](./05-office-field) |
| Кто ждёт согласования | Очередь согласований / поле | [Согласования](./04-trust-and-approval) |
| Когда работали агенты | **Таймлайн** | [Таймлайн](../workflows/timeline) |

## Каналы, данные и файлы

| Ситуация | Вы делаете | Куда |
| --- | --- | --- |
| Клиент пишет в Битрикс24 | Найти задачу → запуск | [Каналы](./06-channels), [Битрикс24](../integrations/bitrix24) |
| Пришло согласование в Телеграм | Решение дублирует панель | [Телеграм](../integrations/telegram) |
| Нужны данные из 1С | Коннектор + Cursor-агент | [1С](./08-1c-bridge), [1С Коннектор](../integrations/1c-connector) |
| Внешний справочник или API | Реестр MCP | [MCP](../integrations/mcp) |
| Клик в браузере | BrowserBridge + токен | [BrowserBridge](../browser/setup) |
| Правка Excel | Вложение → план → согласование | [Документы](./07-documents) |

## Когда звать инженера

| Симптом | Вероятная причина | Документ |
| --- | --- | --- |
| Запуск с ошибкой | Адаптер, секреты, таймаут | [Первый агент](../cloud/first-agent) |
| Инструмент не виден | Плагин не установлен или не выдан | [MCP](../integrations/mcp), [плагины](../cloud/plugins) |
| Excel «висит» | Очередь согласований | [Согласования](./04-trust-and-approval) |
| 1С недоступна | Публикация, авторизация | [1С Коннектор](../integrations/1c-connector) |

## Чего нет в продукте (не обещайте)

- Универсальный доступ любого агента к 1С без Cursor и политики доступа
- Обязательное согласование каждого клика BrowserBridge «из коробки»
- Проведение документов 1С агентом прямо из карточки задачи
- Самостоятельную промышленную установку «скачал репозиторий — поставил сервер» без ИТ
- Встроенный чат внутри карточки конвейера (диалог — через Офис)

## Ключевые факты

- Шпаргалка ведёт на руководства с проверяемыми шагами, а не заменяет их.
- Экспериментальный «Офис» доступен только при включённом флаге.
- Конвейеры и согласования агента — разные очереди.
