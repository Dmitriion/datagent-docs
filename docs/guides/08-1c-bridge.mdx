# Подключите 1С и получите сводку в задаче

<GuideMeta audience="Администратор / ИТ / аналитик" level="Для администратора" />

Как подключить 1С к Datagent: на тарифе **Business+** администратор включает **1С-коннектор**, разработчик 1С публикует доступ, Cursor-агенту выдают разрешение, оператор ставит задачу на сводку. Агент **не проводит документы** в учёте из обычной задачи — он запрашивает данные через контролируемый мост.

Техническая схема: [1С Коннектор](../integrations/1c-connector).

:::info[Тариф]
**Business** (и выше) — подключение 1С-коннектора. [Тарифы](/docs/cloud/pricing).
:::

## Что вы сделаете

- Включите плагин коннектора и проверите связь с базой.
- Разрешите доступ Cursor-агенту.
- Поставите задачу на сводку по данным 1С.

:::caution[Установка]
Нужен доступ к серверу 1С и навыки администрирования. Если специалиста нет — напишите на [sales@datagent.ru](mailto:sales@datagent.ru).
:::

## Шаг 1. Включите плагин

Администратор включает **1С Коннектор** в **Настройки → Плагины**.

## Шаг 2. Опубликуйте доступ и проверьте связь

Разработчик 1С публикует доступ к базе. На странице коннектора нажмите **Проверить соединение**.

![Страница 1С-коннектор в Board](/img/guides/1c/connector-page.webp)

*Страница коннектора: адрес базы, проверка связи и настройки для агента.*

## Шаг 3. Выдайте доступ агенту

Администратор Datagent разрешает нужное подключение 1С в карточке Cursor-агента (вкладка подключений / политика доступа).

## Шаг 4. Поставьте задачу оператору

Пример: «Собери сводку по дебиторке в таблицу». Агент запрашивает данные через коннектор и оформляет результат в задаче.

Примеры запросов (набор зависит от конфигурации 1С):

- «Какие остатки по складу на сегодня?»
- «Покажи продажи за прошлый месяц по менеджерам»

**Не обещайте:** «Агент сам создаст счёт в 1С из чата» — создание документов остаётся в 1С.

### Не путать с

- **MCP** — общий реестр внешних инструментов для Cursor — [MCP](../integrations/mcp).
- **Office Plugin** — Excel/презентации на задаче — [глава 7](./07-documents).

<Checkpoint>
  «Проверить соединение» на странице коннектора успешно; Cursor-агент с доступом отвечает на задачу сводкой по данным 1С в переписке или файле.
</Checkpoint>

## Ключевые факты

- 1С-коннектор доступен с Business+.
- Обычная задача не проводит документы в 1С.
- Нужен Cursor-агент с явным разрешением на подключение.
- Конкретный набор данных зависит от вашей конфигурации 1С.
