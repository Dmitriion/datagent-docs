# Получите результат по файлу на задаче

<GuideMeta audience="Оператор / аналитик" level="Рабочий" />

Как передать документ ИИ-агенту: прикрепите файл к задаче, опишите, что сделать, запустите агента. Для Excel доступен цикл план → согласование → применение. Готовый файл сохраняется как артефакт на тарифах Solo и выше.

Если вы ещё не работали с задачами — сначала [первая задача](./03-one-task). Детали форматов: [Excel и PowerPoint](../office/excel-pptx), [артефакты](../artifacts/overview).

## Что вы сделаете

- Прикрепите файл к задаче.
- Запустите агента с понятным поручением.
- Для Excel — одобрите план правок и скачаете результат.

## Шаг 1. Прикрепите файл

Откройте задачу и нажмите **Прикрепить файл** (или перетащите файл). Подходят Word (`.docx`), PDF, Excel (`.xlsx`), презентации (`.pptx`), текстовые файлы.

## Шаг 2. Назначьте агента с нужным навыком

Убедитесь, что у агента подключён [навык Office](/docs/cloud/skills) (для Excel/PPT на Solo+).

## Шаг 3. Опишите действие и запустите

Напишите конкретно, что изменить, и нажмите **Запустить**. Примеры:

- «Сократи третий раздел до двух абзацев» (Word — рекомендации; правки с пояснениями — Studio+)
- «Добавь столбец „Факт“ на листе Summary» (Excel)

## Шаг 4. Для Excel — согласуйте план

Агент составит **план правок**; вы одобрите его в [согласованиях](./04-trust-and-approval) и получите обновлённый `.xlsx` в **Результате**.

На **Free** агент ответит текстом, но не сохранит файл в медиатеку артефактов. На **Solo+** скачайте файл из **Результата** или каталога **Артефакты**.

:::info[Studio и выше]
Попросите: «Внеси правки и оставь комментарий к каждому изменению». Агент вернёт документ с **аннотациями**. Подробнее — в [обзоре Office](../office/overview).
:::

### Пример: коммерческое предложение

1. Прикрепите КП (Word или PDF).
2. Напишите: «Проверь структуру и предложи, как усилить вступление».
3. Запустите агента и откройте журнал. Для табличной части удобнее Excel с полным циклом plan → одобрение → apply.

<Checkpoint>
  В задаче есть ответ или файл в «Результате»; для Excel — запись об одобренном плане в согласованиях (если правки применялись).
</Checkpoint>

## Ключевые факты

- Полный цикл правок «как в Excel» для готового Word пока недоступен.
- Аннотации в документе — Studio+.
- Артефакты файлов — Solo+; на Free результат остаётся текстом в задаче.
- Рискованное применение Excel всегда проходит через согласования.
